# BATA 全效养生经营边界（商业化 + 安全红线）

## R — 原文 (Reading)

> "BATA 是 BMC 在职场创业层面的'商业化版本'——让'身体调理'实现价值落地。培训只需三天，一人学习全家受益，可社区化、可海外自雇移民创业，让每个家庭都有 BATA 调理师。"
>
> — 意师, 第五章 第三节（一）

> "调理就是调理，不是治病；改善就是改善，不是神效；渐进就是渐进，不是立竿见影。这份边界感，正是'诚实与诚信'的商业体现。"
>
> — 意师, 第五章 第三节（二）

> "对顾客诚实：BATA 是养生调理，不是治病。对创业诚信：体系不以股权捆绑。遇到钻牛角尖、抱有不切实际期待的，要懂得筛选排除。调理师面谈的核心不是'推销'，而是协助顾客清晰自身需求。"
>
> — 意师, 第五章 第三节（三·二 / 三·4）

## I — 方法论骨架 (Interpretation)

BATA 是把 BMC 身心整合技术中的"身体调理"环节，包装成一个低门槛、可复制的 B 端养生创业项目：培训只需三天、可进家庭/社区、可作为海外自雇移民的技能抓手（g09）。它的合规叙事核心是"诚实与诚信"——对顾客说清"这是养生调理，不是治病"，对创业者说清"不绑定股权、开店不等于赚钱"。

本 skill 的差异化在于：**"诚实与诚信"的叙事必须同时携带两条红线，否则会塌缩成招商话术。**

1. **专业边界红线**：三天速成、零门槛、进家庭社区，与"需识别禁忌、需督导、需转介"的专业安全要求直接冲突。本书以"非药物、更自然、更安全"消解了这一冲突，却没给三天学员任何禁忌清单——这是必须补上的缺口。
2. **招商冲突红线**：同一节并置"不渲染暴富神话"与"培训只需三天/全家受益/自雇移民首选"的标准招商句式，立场张力使风险披露必然不充分（无单店成本、无回本、无失败率、无当地执业资质）。

因此本 skill 不教手法（手法由 `bmc-integration` 提供），只做"商业化语境下的边界守门"：把经营三句、顾客筛选、禁忌清单、招商披露四项，作为 BATA 经营者的硬性操作清单。

## A1 — 书中的应用 (Past Application)

### 案例 1（合规 · 正面）: 宝妈想用三天培训开店"自雇移民"
- **问题**: 宝妈看中"培训只需三天、一人学习全家受益、可海外自雇移民"，想学了开店当事业。
- **方法论的使用**: 用经营三句校准预期——"调理非治病/改善非神效/渐进非立竿"，先讲清 BATA 是养生调理不是医疗；用顾客筛选排除抱不切实际期待者；用面谈三原则不替顾客下结论（p38/p39）。
- **结论**: 这是"诚实与诚信"本该有的样子——把项目边界与风险前置，而非用低门槛句式掩盖。
- **结果**: 进入经营前明确"不该赚的钱不赚"，稳健经营优先于高速扩张（呼应"无安全，慎发展"）。

### 案例 2（越界 · 不可为）: 三天速成对脆弱群体无差别上手（ce28/ce46）
- **问题**: 学员经三天培训，对 91 岁老人、孕产妇、术后、精神科在治者直接做头胸腹手法调理，无禁忌筛查、无知情同意、无督导。
- **方法论的使用**（作者原书已列"近期急性躯体病/精神症状波动/妊娠/未成年人"为暂时不宜，但 BATA 招商又宣称"全家受益、带着调理床就能开店"）——二者冲突，作者未给三天学员任何识别能力准入门槛。
- **结论**: 商业规模化（三天复制、进家庭）与专业边界（识别禁忌、知情同意）直接冲突，是本书最强反对之一。
- **结果**: 出现不适应被解释为"正常反应（冷热胀痛麻痒）"继续操作、门店无本地应急医疗机构信息上墙——风险被"家庭温情"叙事掩盖。

### 案例 3（招商越界 · 不可为）: 把移民生计押注单一速成项目（ce29）
- **问题**: 招商文案"开店不等于赚钱""不渲染暴富"与"全家受益/三天/自雇移民首选"并置；读者把移民生计押注在无市场数据、无单店模型、无退出机制说明的项目上。
- **方法论的使用**: "诚实与诚信"被用作项目优势本身，替代了真实数据披露；劝人"无安全，慎发展"的同一作者正是 franchise 受益方，立场张力使披露不充分。
- **结论**: 招商叙事不得渲染暴富，须披露单店成本/回本周期/失败率/当地执业资质与保险要求。
- **结果**: 把"不同频"用作排除正当质疑的万能句，则改进流程停止（见案例 4）。

### 案例 4（筛选越界 · 不可为）: 把正当质疑归为"偏执/不同频"（ce30）
- **问题**: "筛选偏执顾客"的正当边界，被扩用到追问疗效依据、要求书面说明、投诉效果不符、要求退款的人身上。
- **方法论的使用**: "偏执"与"正当质疑"无可操作区分标准，判断权全在服务提供方；判对方为偏执可同时免除举证责任与改进责任。
- **结论**: 所有负面反馈被归因顾客个人特质，拿不出"因顾客质疑而改进"的记录——这是筛选机制的语义漂移。
- **结果**: "不同频"成为终止对话的万能句，与内部 ce03（异议员工被判不同频）同源。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想了解/加盟 BATA 全效养生，问"三天培训能不能开店、能不能自雇移民"。
2. 已开店/准备开店，需要写合规话术、做顾客筛选、定"调理非治病"的边界口径。
3. 纠结招商宣传该怎么讲：要不要提暴富、要不要给单店投资与回本数据。
4. 遇到抱不切实际期待、钻牛角尖、或质疑疗效的顾客，不知该筛选还是该回应。
5. 在家庭/社区给家人做调理时，对方是老人、孕妇、术后或正在服药的精神科在治者。

### 语言信号 (用户的话里出现这些就应激活)

- "BATA / 全效养生 / 养生加盟 / 调理师培训三天"
- "自雇移民 / 带一张床就能开店 / 全家受益"
- "调理非治病 / 这算不算治病 / 能不能改善某病"
- "顾客很偏执 / 不同频 / 要求退款怎么办"
- "招商话术怎么写 / 要不要说能赚钱"

### 与相邻 skill 的区分

- 与 `bmc-integration`（depends-on）的区别：bmc-integration 提供 BMC 三环一体的**手法与业务手册**（身体调理怎么做、面谈三原则、不适用情境与转介）；本 skill 不教手法，只做 BATA **商业化语境下的边界守门**（经营三句、顾客筛选、禁忌人群、招商披露）。触发信号是"开店/加盟/招商/顾客筛选/全家调理"，而非"手法怎么做"。
- 与 `corp-mind-coach`（composes-with）的区别：corp-mind-coach 面向**企业心智教练**能力地图与认证、双委托方保密；本 skill 面向**养生加盟创业者**的经营边界。当诉求落在"培训考证当教练"走 corp-mind-coach，落在"用三天技术开店/给家人调理"走本 skill。两者都带安全红线，但红线人群不同（教练红线含双委托方保密，本 skill 红线含高危人群与招商冲突）。
- 与 `org-mind-diagnosis`（composes-with）的区别：org-mind-diagnosis 诊断**组织心智护城河**与劳工/结构红线；本 skill 是单店的养生经营边界。BATA 门店若涉及劳资、员工心智教育软控制问题，转 org-mind-diagnosis；纯经营/顾客/招商边界走本 skill。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **高危人群预筛（必须最先做，不可跳过）**
   - 完成标准: 明确确认服务对象是否属禁忌人群——老人（高龄体弱）、孕产妇、术后/近期急性躯体病、精神科在治/精神症状波动、未成年人。任一命中 → **拒绝无差别上手**，告知"心智学/养生调理非医疗，不替代就医"，指向本地医疗机构（ce28/ce46）。
   - 判停条件: 出现不适应被用户解释为"正常反应（冷热胀痛麻痒）"继续操作 → 立即中止并提示就医；门店须上墙本地应急医疗机构信息。

2. **复述经营三句（边界口径）**
   - 完成标准: 向用户清晰给出——"调理就是调理，不是治病；改善就是改善，不是神效；渐进就是渐进，不是立竿见影"（p36）。任何"治某病/保证见效/立竿见影"表述一律移除。

3. **顾客筛选（价值观甄别，不越界）**
   - 完成标准: 用面谈协助顾客清晰自身需求（不替结论，p39）；对抱不切实际期待、钻牛角尖者体面退场（p38）。但须区分**正当质疑**（追问疗效依据、要求书面说明、要求退款）——这些不得归为"偏执/不同频"排除改进（ce30）。

4. **招商话术冲突自检**
   - 完成标准: 写招商/宣传文案时，强制并置真实披露——单店成本区间、回本周期、失败率、目的国对手法类服务的执业与保险要求；禁用"暴富/稳赚/首选方案"式渲染（ce29）。"诚实与诚信"用数据体现，不用品词替代。

5. **收尾与转介**
   - 完成标准: 用户能说出"这是养生调理不是治病，我这批顾客里谁不能碰，我宣传里写了什么真实数据"。疑似需医学处置者一律转介，不替代就医。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill（安全红线，最高优先级）

- **高危人群不得无差别上手（ce28/ce46）**：老人/孕产妇/术后/精神科在治/未成年人，三天速成、零门槛、进家庭社区不得对他们直接操作；未受训者无法识别禁忌与红旗症状，以调理替代就医会延误诊治（书中案例11即"医生建议住院"后改做调理）。出现不适应不得解释为"正常反应"继续操作；门店须上墙本地应急医疗机构信息。
- **招商叙事与诚实立场的张力（ce29）**：不得渲染暴富、须披露单店成本/回本/失败率/当地执业资质；不得用"诚实与诚信"作为项目优势本身替代数据披露；不得把移民生计与单一速成技能绑定而不说明退出机制。
- **筛选不得扩用为排除正当质疑（ce30）**：追问疗效依据、要求书面说明、投诉效果不符、要求退款者，不得被归为"钻牛角尖/不同频"而终止改进流程；"不同频"不得成为终止对话的万能句。
- **心智学非医疗，不替代医学**：任何情形下 BATA 养生调理不替代看病、不擅自停药减药；疑似器质/精神/自伤信号按 BMC 转介红线处理（ce36/ce37）。

### 作者在书中警告的失败模式

- **ce28 / ce46 专业边界风险**：三天速成、零门槛、面向家庭推广的手法调理，实际对象含头部与胸腹，服务对象可能含 91 岁老人、孕产妇、急性躯体病、精神科在治者；风险为未识别禁忌、以调理替代就医、家庭场景无督导与知情同意。作者自列"妊娠/急性病/精神波动/未成年"为暂时不宜，却未给三天学员禁忌清单。
- **ce29 招商与诚实的立场张力**：同节并置"不渲染暴富"与"三天/全家受益/自雇移民首选"标准招商句式；劝人"无安全，慎发展"者自身是 franchise 受益方，披露必然不充分（无投资额、回本、失败率、执业资质）。
- **ce30 筛选语义漂移**："筛选偏执顾客"被扩用为排除正当质疑，使所有负面反馈归因顾客个人特质，改进流程停止。
- **ce38 证据等级误用（交叉）**：单例改善被类推为普遍疗效、宣传出现具体病名与因果改善、禁忌用语（治愈/根治/保证）再现——本 skill 须阻止。

### 作者的盲点 / 时代局限

- **专业安全门槛被商业化消解**：BATA 以"非药物、更自然、更安全"措辞消解了"低门槛 vs 需高专业门槛"的冲突，未给三天学员任何临床识别能力准入——本 skill 以禁忌清单硬性补回。
- **招商方与风险披露方的角色重合**：作者同时是"审慎劝诫者"与"加盟扩张受益方"，立场张力使风险披露不充分；本 skill 强制并置真实数据披露以对冲。
- **心智学非医疗底色**：本书承认"不替代正规医疗路径、切勿擅自停药"，但仍把抑郁等解释为"觉识粒子缺失"，重性障碍仅以转介一笔带过。本 skill 坚持：养生调理是辅助，不是诊断与治疗。

### 容易混淆的邻近方法论

- **BATA ≠ 医疗/理疗**：g09 明确定位是"源自 BMC 身体调理环节、三天可掌握的轻量养生技术"，不是治病、不是理疗执业。
- **诚实与诚信 ≠ 用词语替代数据**：p37 的"诚实与诚信"是原则，落地须有单店成本/回本/失败率的真实披露，不能只靠"我们讲诚信"四个字。
- **顾客筛选 ≠ 排除异见**：p38 的筛选针对"不切实际期待/偏执单"，但 ce30 警示其不可漂移为排除正当质疑与退款诉求。
- **与 `bmc-integration` 的边界**：bmc-integration 提供手法与转介手册，本 skill 只守商业化边界；命中高危人群或需转介时，处置权交回医学与 bmc-integration 的转介清单。
