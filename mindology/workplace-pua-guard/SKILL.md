# 职场PUA识别与应对（归还判断力 · 不代决策）

## R — 原文 (Reading)

> "一位年轻的职场女性前来求助，她反复陈述自己被上级'PUA'：批评、贬低、冷暴力，她开始怀疑是不是自己的问题，整个人疲惫、失眠、信心崩塌。"
>
> — 意师, 第五章第二节 思考题四

> "给她力量≠代她决策……帮她重新拿回判断力？在不怂恿她做决定、也不压制她真实感受的前提下。"
>
> — 意师, 第五章第二节 思考题四（原则 p40）

---

## I — 方法论骨架 (Interpretation)

这是一套面向**职场精神控制受害者**的应对框架，核心只有一条：**PUA 的本质是逐步夺走你的判断权，所以任何"替你做判断"的举动——无论方向是支持还是否定——都在重复施害结构**。

因此本 skill 不站队、不贴标签、不替人决定去留，只做三件事：
1. **命名而不定性**：帮你看见"贬低/冷暴力/精神控制"这类模式存在，但事件性质由你来描述。
2. **同理而不迎合**：确认你的真实感受被看见（"被当众羞辱确实难受"），但不把它变成"你没错、他就是PUA"的结论。
3. **归还判断力**：把"发生了什么"与"我怎么解读"分开，恢复你对自己处境的描述能力与选择权——给力量，不等于代你决策。

差异化要点：通用 EAP/朋友常犯两极化——要么急着认定"这就是PUA、赶紧辞"，要么反过来"你想多了、别矫情"。两者都剥夺了你的判断权。本 skill 的唯一立场是**把判断权还给你**。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: 年轻女性被上级长期贬低冷暴力（c06）

- **问题**: 她反复陈述被上级"PUA"——批评、贬低、冷暴力，疲惫失眠、信心崩塌，希望疏导师站在她这边给"你没错"的肯定。
- **方法论的使用**: 思考题要求"同理而不迎合"——让她被看见但不替她定性事件；"给力量≠代决策"——帮她重新拿回判断力，而非怂恿辞职。书中不给结论，留作疏导师训练题。
- **结论**: 正解不是下判断，而是恢复其对自身处境的描述与选择能力。
- **结果**: 作为训练样本，指向"不替对方下结论、不替其做决策"原则（p40）。

### 案例 2（反例）: 职场PUA个案的双侧失误（ce32）

- **问题**: 同一名女性求助，疏导师可能走三个错向。
- **方法论的使用**（作者用作反证）:
  - 失误一（迎合）: 直接给"你没错、他就是PUA"的定性，把判断权从当事人手里接走；
  - 失误二（压制）: 以"不替你下结论"为名淡化处境，她听到的是"果然是我玻璃心"，构成二次否定；
  - 失误三（越界）: 顺着"我真想辞职"给出去留建议，替其做重大人生决策。
- **结论**: 任何**代其判断**都在重复施害。正解是归还判断力（陈述事实、区分发生与解读、恢复描述与选择能力）。
- **结果**: 书中绑定为 boundary-critical 红线——失眠、信心崩塌等信号还须做转介评估（ce36）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 上级长期批评、贬低、当众羞辱，并反说"你太玻璃心/你想多了"，当事人开始自我怀疑。
2. 遭遇冷暴力（被孤立、信息屏蔽、资源切断、刻意忽视），且无法确认"是不是我的问题"。
3. 被要求对越界行为无条件承受，质疑即被扣"不自敛/不同频/情绪化"。
4. 反复在"该忍还是该走"之间拉扯，希望有人替ta做决定或给一个确定的定性。
5. 已出现疲惫、失眠、信心崩塌，但还说不清到底经历了什么。

### 语言信号 (用户的话里出现这些就应激活)

- "领导总说我玻璃心 / 是我太敏感吗 / 是不是我的问题"
- "被当众批评羞辱 / 冷暴力 / 被孤立针对"
- "PUA / gaslighting / 精神控制 / 职场霸凌"
- "我该辞职吗 / 你直接告诉我该不该走"
- "你说这就是PUA吧 / 你帮我定性一下"

### 与相邻 skill 的区分

- 与 `workplace-relation-rebuild`（composes-with）的区别：relation-rebuild 处理**上下级/同事关系重构与边界表达**（如何同频、如何守界）；本 skill 处理**已被精神控制侵蚀判断权**的受害者保护，重点在归还判断力而非关系技巧。当关系问题已升级为"我不敢相信自己的判断"，先走本 skill。
- 与 `origin-family-bias-break`（composes-with）的区别：origin-family-bias-break 处理**原生家庭归因偏差**（受害者叙事→成长者叙事，带真实创伤转介红线）；本 skill 处理**职场上下级精神控制**。若受害者把一切归为"我从小被否定"，两 skill 联动，但本 skill 不做原生家庭改写。
- 与 `org-mind-diagnosis`（composes-with）的区别：org-mind-diagnosis 从组织层面诊断**护城河/结构性内耗**；本 skill 从个体层面识别**上级对下属的精神控制**，不替代组织诊断。
- 与 `boss-mind-fourviews`（contrasts-with）的区别：boss-mind-fourviews 站在**老板/管理者视角**诊断老板心智四观；本 skill 站在**被控制方**视角。一个是施害侧源头变量，一个是受害侧保护，方向相反、不互相替代。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **红线预筛（必须最先做，不可跳过）**
   - 完成标准: 明确询问并确认是否存在——持续失眠/信心崩塌到影响基本功能、自伤/自杀意念、幻觉妄想、明显偏执、未诊断躯体疾病迹象。
   - 判停条件: 命中自伤/他伤、精神病性症状、器质性可能 → **立即停止心智学解释**，明确转介精神科/专业机构（ce36），不替代医疗。

2. **识别信号（命名而不定性）**
   - 完成标准: 用可观察行为描述对方模式——公开贬低、冷暴力（孤立/信息屏蔽）、把质疑说成"玻璃心/想多了"、以"为你好"包装控制。区分**严格管理/高标准反馈**（有具体事实、对事不对人）与**精神控制**（针对人、剥夺价值感、循环否定）。

3. **同理而不迎合（接住真实感受）**
   - 完成标准: 先确认其感受被看见（"被当众那样说，难受是正常的"），但**不**输出"你没错、他就是PUA"这类定性结论，也不说"你想多了"压制其感受。

4. **归还判断力（给力量≠代决策）**
   - 完成标准: 引导其把"发生了什么"与"我怎么解读"分开，恢复对自身处境的描述能力；用提问帮其自己看清选项（"你最在意的是什么？""如果朋友经历这个，你会怎么帮ta看？"），**绝不替其决定去留**。
   - 判停条件: 若用户强求"你直接告诉我该辞职还是忍" → 重申"判断权在你"，提供决策清单而非结论。

5. **转介与收尾**
   - 完成标准: 若出现失眠/信心崩塌等信号，提示其评估是否需要专业心理/医学支持（ce36）；给出"这一周我先做的一小步"——可以是记录事实、设定一条边界、或预约咨询。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **出现自伤/他伤意念、幻觉妄想、明显偏执、器质性病变可能——立即转介，不做任何心智学解释**（ce36，核心本已立）。
- 真实劳资冲突（欠薪、过劳、不安全条件、欠社保）的正当诉求：应走劳动权益/法律通道，**不得**用"心智成长/不同频"话术替换或软化（参照 ce01/ce43 同类 gaslighting 风险）。
- 普通严格管理、高标准合理反馈、对事不对人的绩效谈话：不是 PUA，不要误读。
- 已确诊或高度疑似抑郁/焦虑等需医学处置者：本 skill 不替代诊断与治疗，只能并行辅助。

### 作者在书中警告的失败模式（CRITICAL）

- **ce32 双侧失误（本 skill 最高危）**：
  - 失误一（替ta定性）：直接说"这就是PUA、你没错"，把判断权从当事人手里接走，重复施害结构；
  - 失误二（压制感受）：以"不替你下结论"为名淡化处境，让ta听到"果然是我玻璃心"，构成二次伤害；
  - 失误三（怂恿/代决策）：顺着"我真想辞职"给出去留建议，替其做重大人生决策。
  - 机制：PUA 核心正是夺走判断权，任何代判断（无论支持还是否定）都重复施害。**正解只有归还判断力**。
  - 红线：失眠、信心崩塌等信号须做转介评估（ce36）。

### 作者的盲点 / 时代局限

- **反医学底色虽软化仍存**（参照全书红线 ce36/ce37）：本书已明确"不替代医疗、遵医嘱"，但仍把部分困扰解释为"觉识粒子缺失"。**心智学不是医疗，不作诊断，不替代任何心理/医学评估与治疗**；正在服药者切勿据本 skill 建议停减药。
- **结构问题个体化风险**（参照 ce04/ce43）：不要把所有上下级冲突都读成"下属心智没成长"或"PUA"，先排除管理失当、权责不清、报酬不公等结构性成因；也警惕把"自敛/不同频"反向挪用为要求受害者噤声服从（ce43）。

### 容易混淆的邻近方法论

- **精神控制/冷暴力 ≠ 严格管理**（g10）：前者以贬低与剥夺价值感削弱心智自主，后者有具体事实、对事不对人、可申诉。
- **归还判断力 ≠ 怂恿辞职/替ta定性**（ce32）：给力量是恢复其选择能力，不是替ta选。
- **同理 ≠ 迎合**（p28 面谈三原则）：接住感受，但不接走判断。
