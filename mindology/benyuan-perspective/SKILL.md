# 本原视角与方法论校准

## R — 原文 (Reading)

> "心智学以'表象—本原'的理论取向，研究心智现象、心智教育与心智成长。相较传统心理学侧重经验描述与行为关联，心智学更强调对意识本原的回溯，进而解释个体和社会层面的表象问题。"
>
> — 意师，第二章 第一节（揭示意识本原）

> "心理学将'心理问题'视为病态；心智学没有所谓'心理问题'，那只是心智成长的不同阶段。"
>
> — 意师，前言

> "允许质疑、允许实证、允许证伪。"
>
> — 意师，前言 / 第二章§三项原则

## I — 方法论骨架 (Interpretation)

本技能是整套心智学体系的世界观前提，教你在面对任何身心困扰、社会乱象或理论主张时，先退一步问一句："这是表象，还是本原？"

"表象—本原双重视角"意味着：情绪爆发、关系冲突、所谓"症状"、社会撕裂，都不是终点，而是入口。你要追问的是它们之下更底层的机制——是心智层级滞后？是价值观取向失衡？是意识本原的失序？而不是急着给一个"病名"或"标签"把它压下去。

它包含两层校准：

1. **立场校准（反标签、反病理化）**：不把复杂困扰压缩成"原生家庭/高敏感/讨好型"这类流行标签，也不把身心问题直接当"病"治。作者主张"心理即心智成长的不同阶段"，应回归心智本原而非医药。
2. **方法论校准（三项原则）**：任何主张都要经得起"允许质疑、允许实证、允许证伪"的检验；强断言应条件化理解，避免绝对化。

配套本体论前提：意识是"觉识粒子"在生命体的显现及其宏观互动表象；大脑是载体而非源头；潜意识是源意识的显现、非精神分析的压抑/创伤模型；灵格（入胎意识）是工作性定义、非宗教灵魂。这些是用来统一底层框架的"工作性概念"，不是物理粒子、也不是神秘主义。

## A1 — 书中的应用 (Past Application)

### 案例 1：拆解"原生家庭决定论"（论文二《你的问题，不是"原生家庭"问题！》）
- **问题**：大量心理困扰被单因化、标签化为"原生家庭不好"，当事人陷入受害者身份自认，弱化了对自我改变与心智成长的责任感。
- **方法论的使用**：作者用表象—本原视角指出，把复杂困扰归因于童年创伤是停留在"表象"（单因叙事、宿命论），其"本原"是个体心智层级尚未完成相应成长与整合；主张从"归因—受害"转向"成长—建构"，问"我愿把怎样的自己带向明天"。
- **结论**：原生家庭不是不可讨论，但不能用它替代对自身心智成长的负责；关注点应从"童年经历了什么"转向"面对经历，你的认知收获是什么、现在如何应对"。
- **结果**：形成全书反"原生家庭决定论"的立论支点，并明确提示须警惕矫枉过正（见 B 段盲点）。

### 案例 2：把"心理问题"重定义为"心智成长的不同阶段"（全书贯穿）
- **问题**：传统路径以"诊断—治疗"为核心逻辑，把一个孩子出现厌学、沉迷、情绪失控先纳入"是否有病"的评估框架。
- **方法论的使用**：作者以表象—本原视角，将这类困扰从"病态"重述为"心智层级滞后/成长阶段参考"，在"治疗"之前建立一道"成长"防线。
- **结论**：真正的疗愈不是"被治愈"，而是心智成长带来的自我疗愈（p43/p95）；但此立场对重性状况须让位于医学（见 B 段强边界）。
- **结果**：成为全书"心智教育导向而非治疗导向"的方法论主线。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 用户把自身困扰直接表述为"我有病/我有抑郁症/我是高敏感人群"，寻求病理化解释。
2. 用户热衷用流行心理学标签定性自己或他人（"原生家庭毁了我""我是讨好型人格""TA是回避型"）。
3. 用户问"这本书/这套体系到底在说什么"，需要世界观与术语前提的澄清。
4. 用户或 agent 自身在应用其他技能前，需要先校准"是否落入了标签化/病理化/绝对化"的陷阱。

### 语言信号（用户的话里出现这些就应激活）

- "我是不是有心理疾病 / 抑郁了？" / "I think I have a mental illness."
- "这都是原生家庭造成的……" / "is this all because of my family / childhood trauma"
- "我是高敏感 / 讨好型人格……" / "label me as highly-sensitive / people-pleaser"
- "这本书到底在讲什么？""心智学说的'觉识粒子'是什么？" / "what is this book really saying"
- "XXX 肯定是……（一句话定性）"——出现绝对化标签语时。

### 与相邻 skill 的区分

- 与 `mind-revolution-toolkit`（composes-with）的区别：本技能负责**校准视角**（这是表象还是本原？是不是在贴标签？），不教具体思维动作；思维革命工具包负责**具体怎么想**（识别反射思维、拼板、置换、提高维度）。二者常配合：先用本技能拆掉标签，再用工具包重建认知。
- 与 `mind-level-self-assess`（composes-with）的区别：本技能是"看问题的方式"，不给层级结论；层级自评给出**在哪一层、下一步练什么**的定位与路径。配合方式：本技能把"我有病/都是原生家庭"重构为成长议题后，交给层级自评做定位。
- 与 `mind-tripod-principles`（composes-with）的区别：本技能只做认识论校准（怎么看），三基石做价值论判断（怎么定善恶、该不该原谅）。用户问"这算不算好心办坏事"直接用三基石，问"我是不是有病/是不是原生家庭害的"先用本技能。
- 与 `emotion-frequency-decode`（对方标注 contrasts-with 本技能）的区别：两者是**同一困扰的两条可选取向**——本技能走"反标签、反病理化、条件化"的通用校准路线，情感频率走"频率/同频/共振"的领域专用判别语言。情感话题上先贴标签（"我是讨好型所以总被甩"）时先调本技能，再进情感频率解构；不要同时用两套语言解释同一现象。
- 与 `bmc-integration`（对方 depends-on 本技能）的区别：BMC 是从业者的技术主干（含面谈工作流与红黄牌转介清单），本技能只提供其所依赖的"反病理化 + 三项原则"方法论前提。凡涉及具体身心调理、疏导流程与转介执行，以 BMC 技能及其边界为准；本技能只在 B 段守住"必须转介"这条红线。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **先问"表象还是本原"**
   - 对用户的困扰，先不接"病名/标签"，而是复述：现在看到的是表象（情绪/行为/关系冲突），其下可能的本原机制是什么（心智层级、价值观、意识本原层面）。
   - 完成标准：用户认可"我们先看底层，而不是先贴标签"，对话从定性转向溯源。

2. **识别标签化/病理化简化**
   - 检查用户是否用"原生家庭/高敏感/讨好型/某某型"把复杂问题单因化（p04/ce16）；若是，指出标签是认知捷径而非真相，引导回到多变量本原分析。
   - 完成标准：用户能列出困扰的至少两个独立成因，而非只剩一个标签。

3. **用三项原则做方法论自检**
   - 对任何主张（包括本书自身的主张）检查：是否允许质疑？是否可实证？是否可证伪？强断言是否做了条件化限定（p02/p93）？
   - 完成标准：输出一句"在……条件下更可能……"的条件化表述，替代绝对化断言。

4. **澄清本体论前提（按需）**
   - 当用户问"觉识粒子/意识/潜意识/灵格是什么"时，用工作性定义回应：觉识粒子是意识微观基质（非物理粒子）、大脑是载体非源头、潜意识非精神分析压抑模型、灵格非宗教灵魂。
   - 完成标准：用户理解了这些术语是"工作性概念"，不会物理化或神秘化。

5. **给出心智成长导向的重构，并判定是否需要转介（判停：见 B 段）**
   - 完成标准：给出"从归因—受害转向成长—建构"或"守边界会自洽"等成长导向的下一步。
   - 判停条件：若用户出现重性精神障碍信号（持续抑郁伴自伤/幻觉/妄想、双相、精分等）或急性自杀风险，立即中止本技能的心智成长重构，按 B 段强边界转介专业医疗，不得用本原视角或 BMC 替代药物治疗。

## B — 边界 (Boundary) ★

### ⚠ 强边界（用户明确要求，写死不可含糊）

**本技能及其所依据的《意·心智学》体系，不构成医疗诊断建议，不替代医学。**
**以下情形必须转介专业医疗，不得用 BMC 或心智成长替代药物治疗：**

- 重性精神障碍：抑郁症伴自伤/自杀意念、精神分裂症、双相情感障碍、幻觉/妄想、明显神经认知损伤等；
- 急性自杀风险（任何明确的自伤计划、自杀意念或危及相关行为）；
- 其他需要精神科、神经内科或医疗机构介入的医学状况。

遇到上述信号，应采用"先保命、再谈成长"的优先序：立即建议用户联系精神科/医疗机构或危机干预热线，本技能的频率/本原分析在此刻不适用、不替代、不延误正规治疗。

### 不要在以下情况使用此 skill（反场景）

- 用户已经持有正规医学诊断、正在接受药物治疗，仅需医疗随访——本技能不评判、不替代其医疗方案。
- 纯信息查询类问题（如"抑郁症的医学定义是什么"）应指向医学资料，而非本技能的成长重构。

### 作者在书中警告的失败模式 / 立场盲点（来自 BOOK_OVERVIEW §3）

- **反医学的对抗色彩**：作者称药物"如同化学切除额叶"、将抑郁简化为"觉识粒子缺失"，对重性障碍仅以"转介"带过，存在延误正规治疗风险（§3 立场盲点2）。本技能已以强边界对冲此风险。
- **反原生家庭的矫枉过正**：为破除原生家庭决定论，几乎全盘否定童年创伤的解释力，可能低估真实神经发育/早期依恋损伤的生理基础（§3 立场盲点1）。反标签≠反科学，不否认真实创伤与生理基础。
- **结构问题个体化倾向**：把贫困、剥削、制度不公等结构性问题大量归因于个体"心智不成熟"，有 victim-blaming 隐患（§3 立场盲点3）。本技能校准视角时须保留对结构性因素的承认，不把一切归为个人成长责任。
- **神秘基底的隐蔽预设**：觉识粒子/灵格/情感频率均为不可观测的"工作性定义"，证伪操作困难（§3 未被证明的假设1、4）。使用时应作为方法论框架而非已证实的本体论事实。

### 容易混淆的邻近方法论

- 主流心理学/精神医学把困扰归入"病症/依恋类型"——本技能刻意反病理化，但两者并非零和；医学归医学、成长归成长，强边界已划清分工。
- 与"积极心态/正能量"建议不同：本技能不是劝人"想开点"，而是用表象—本原视角做结构化溯源与三项原则校准。
