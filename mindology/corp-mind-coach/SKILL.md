# 企业心智教练能力地图 + IAMS 认证（含双委托方与医学红线）

## R — 原文 (Reading)

> "第一重·心智践行者（自己先完成修识践行）；第二重·身心疏导师（掌握 BMC 基本功）；第三重·企业教练员（把概念解析成日常语言赋能）。三重能力合一，才是优秀企业心智教练。"
>
> — 意师, 第六章 第四节

> "企业心智教练培训分三阶段：1、心智学理论筑基（自我评估）；2、BMC 技能培训（独立个案 ≥30 例）；3、企业心智教练（落地组织日常，独立合作一家企业并提交记录）。"
>
> — 意师, 第六章 第四节

> "六类适合人群：1、HR/OD；2、心理咨询师/治疗师；3、培训讲师/顾问；4、管理者/创业者；5、教育工作者/社工；6、医生/康复师/健康管理师。各凭邻近能力完成跃迁。"
>
> — 意师, 第六章 第四节

## I — 方法论骨架 (Interpretation)

这是一张"企业心智教练从业能力 + 认证路径"的地图，把"谁能做、怎么成长、认证含金量"三件事并成一张表。

**三重能力模型（f16/p58）**——优秀教练不是只懂讲课，而是三环叠加：
- **第一重·心智践行者**：自己先完成心智成长与修识践行，不是用道理教人，是用活出来的状态影响人。这一重是底座，缺了它，后面两层都是空壳。
- **第二重·身心疏导师**：掌握 BMC（Body-Mind-Consciousness 整合）基本功，能一对一做身心疏导（详见核心本 `bmc-integration`）。
- **第三重·企业教练员**：把心智学概念译成组织能听懂的日常语言，把理念落到会议、考核、协作里赋能团队。

**三阶段成长路径（f17）**——认知（理论筑基 + 自我评估）→ 方法论（BMC 技能培训，独立个案 ≥30 例）→ 企业践行（陪跑一家企业、提交落地记录）。是一条"先修己、再上手、后落地"的进阶链。

**六类适任人群（f19）**——HR/OD、咨询师、培训师、管理者/创业者、教育工作者/社工、医生/康复师，各自有邻近能力可迁移，但都要补齐缺的那一两重。

**但本 skill 必须带两条红线，不能只讲"风口"**：
1. **认证与双委托方边界（ce31/ce34/ce47）**：IAMS 证书由体系自身颁发、两年一审、复训自审，外部无第三方效力；企业付费场景下疏导师同时面对"买单公司"和"坐在面前的员工"两个委托方，保密失守即摧毁可信度。
2. **医学/转介红线（ce36–ce38）**：心智学非医疗，非医学背景不得独立做个体个案；出现自伤/他伤、精神障碍疑似、器质病变必须转介。

## A1 — 书中的应用 (Past Application)

### 案例 1: 退休教师想考企业心智教练证转行（ce31 / ce47 边界案例）

- **问题**: 一位刚退休的教师看到"心智产业蓝海、未来最稳职业方向、站在风口"的宣传，想花培训费考取 IAMS 中级认证后"独立开展 BMC 个案"转行。
- **方法论的使用**: 用六类适任人群核对——教育工作者属第五类，邻近能力（讲台、共情、结构化表达）确实可迁移；用三阶段路径判断其处在"理论筑基"起点，距"独立个案"还差 BMC ≥30 例与陪跑一家企业两段。再用认证边界核对（ce31/ce47）：该证书由发证体系自我背书、无第三方劳动力市场效力，"中级即可独立开展个案"与其非医学背景不匹配。
- **结论**: 路径可行，但须明示——这是体系内自证资质，不是国家执业资格；转行预期应建立在"邻近能力迁移 + 真实个案积累"上，而非"风口叙事 + 一张证"。
- **结果**: 避免把"考证"误读为"拿到上岗通行证"，也避免其在无督导下对客户独立下手（医学/专业风险）。

### 案例 2: "是公司让我来的"——企业付费个案的双委托方冲突（ce34）

- **问题**: 一家公司采购员工心智服务，HR 事后索要"谁情绪不稳、谁想离职"的个体反馈，准备进入用人决策。
- **方法论的使用**: 用 ce34 框架识别双委托方冲突：买单方（公司，希望员工继续高效）与服务对象（员工，可能想离开）诉求可能对立。事前书面约定反馈口径——只回报聚合数据、不回报可识别个体内容；员工须被明确告知哪些信息会/不会回传。
- **结论**: 不交出可识别个体信息，否则一次泄露即摧毁整个企业心智服务的可信度，且可能成为"不同频请退"（ce03）的输入。
- **结果**: 守住保密边界，服务关系可持续；若事前未书面约定、事后被单向施压，应立即体面中止而非强行推进。

### 案例 3: 深夜来访的"高绩效员工"——得体防御掩盖崩溃前兆（ce33）

- **问题**: 一位一身西装、条理清晰的高管来访者，面谈 20 分钟只谈 KPI、项目细节，反复说"只是需要调一调睡眠"，并冒出一句"怕自己哪天会顶不住"。
- **方法论的使用**: 用 ce33 框架识别"得体的防御"——体面、配合的外表下，功能维持良好与自伤风险可以并存；"顶不住"是转介红线信号（委婉的自伤意念表达）。不能只按点单项目（"我只要能睡好"）服务，也不能过度反应强行戳破其体面导致脱落。
- **结论**: 以平静、不评判的方式追问该表述，做风险评估；一旦确认自伤意念，立即启动转介（ce36），不继续在心智成长框架里"调睡眠"。
- **结果**: 高功能来访者不被低风险误判，红线不被表面功能水平误导。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想转行/兼职做"企业心智教练"，问"我适不适合、要先考什么证、IAMS 认证靠谱吗"。
2. 已经是 HR/培训师/咨询师/管理者，想把自己的能力升级成"能给企业做心智教练"，问三阶段路径怎么走。
3. 拿到 BMC 基础、做过一些个案，问"我够不够格独立接企业单、怎么陪跑一家企业"。
4. 所在公司采购了员工心智服务，被问"反馈怎么给公司、员工隐私怎么保"。
5. 想了解这套认证的外部效力、与心理咨询/教练(EAP)资质的区别。

### 语言信号 (用户的话里出现这些就应激活)

- "我想考企业心智教练 / 想做 corporate mind coach / IAMS 认证怎么考"
- "心智教练培训 / mind coach training / 三重能力 / 陪跑一家企业"
- "我适合做教练吗 / 六类适任人群里有我吗 / who is fit to be a coach"
- "中级就能独立做 BMC 个案吗 / 这个证外面认不认"
- "公司让我给员工做心智服务，反馈要报给老板吗"

### 与相邻 skill 的区分

- 与 `bmc-integration`（depends-on）的区别：bmc-integration 是**核心本 BMC 三环技术本体**（身体调理/心智疏导/意识强化），本 skill 只把它当作第二重能力的"前提"复用，不重新定义技术；需要具体疏导手法时转到它。
- 与 `org-mind-diagnosis`（composes-with）的区别：用户问"我怎么成为能服务企业的教练、路径与资质"→ 本 skill；用户问"我们公司组织心智健不健康、成人型心智占比多少、护城河深浅"→ org-mind-diagnosis。前者是**从业者能力地图**，后者是**组织诊断工具**，常串联（教练用诊断工具服务企业）。
- 与 `boss-mind-fourviews`（composes-with）的区别：本 skill 涉及"老板心智私教"只是六类人群之一的应用场景；用户专注"老板四观怎么诊断、利益/员工/风险/价值观观失衡"→ boss-mind-fourviews。
- 与 `value-business-hr`（contrasts-with）的区别：企业采购心智服务若滑向"把低薪/过劳/欠社保软化为心智不成熟、以不同频请退"（ce01/ce03），**不在本 skill 范围**，转 value-business-hr 的劳工红线处理。
- 与 `workplace-pua-guard`（contrasts-with）的区别：员工被上级精神控制、要拿回判断力 → workplace-pua-guard；本 skill 是教练侧的能力与边界，不处理具体受害者的疏导话术。
- 与 `bata-business-boundary`（contrasts-with）的区别：BMC 身体调理的 B 端加盟经营边界（三天培训/禁忌人群/招商冲突）→ bata-business-boundary；本 skill 聚焦教练认证与组织落地，不覆盖养生加盟。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **红线预筛（必须最先做，不可跳过）**
   - 完成标准: 明确询问是否出现自伤/他伤意念或行为、幻觉妄想等精神病性症状、明显器质病变可能、正在服药者是否被动停减药。
   - 判停条件: 命中任意一项 → **立即停止心智学/教练框架解释**，告知需精神科/临床医学评估，转 `bmc-integration` 的转介清单（ce36–ce38）；非医学背景者不得独立做个体个案。

2. **三重能力自评**
   - 完成标准: 让用户逐重打分——第一重践行者（自己心智成长修识到哪一步）、第二重疏导师（是否掌握 BMC、有无督导下个案）、第三重教练员（能否把概念译成组织日常语言）。明确第一重不可缺，缺哪重就补哪重。
   - 完成标准（补充）: 输出"三环缺口图"，指出当前最强与最弱的一重。

3. **三阶段路径匹配**
   - 完成标准: 按 f17 定位用户所处阶段（理论筑基 / BMC 技能培训≥30 例 / 企业教练陪跑一家企业），给出下一阶段的明确动作与结业标志（如 ≥30 例需有记录、陪跑需提交落地记录）。
   - 判停条件: 若用户想"跳阶段直接接企业单" → 提示 ce47（自证闭环存疑）与 ce31（无第三方效力），先补齐 BMC 实操与督导。

4. **六类人群匹配**
   - 完成标准: 按 f19 判定用户属于六类中的哪类，列出其**可迁移的邻近能力**与**必须补齐的缺口**（如教师补 BMC 手法、管理者补疏导师视角、咨询师补企业落地语言）。

5. **认证与边界明示**
   - 完成标准: 向用户讲清 IAMS 证书由体系自颁自审、外部无第三方效力（ce31/ce47）；若涉及企业付费服务，必须事前书面约定双委托方反馈口径（只报聚合数据、不报个体内容，ce34）。
   - 完成标准（补充）: 用户能复述"这张证不等于国家执业资格、非医学背景不能独立做个体个案"。

6. **复检与收尾**
   - 完成标准: 约定下一步——补哪重能力、走哪阶段、找什么督导/陪跑企业；并再次强调医学红线不跨。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **出现自伤/他伤意念或行为、幻觉妄想、精神障碍疑似、器质病变可能——立即转介精神科/临床，本体系非医疗、非医学背景不得独立做个体个案**（ce36–ce38）。把"心理问题都是心智问题"的总纲外推到医学情形，会系统性降低对医学信号的警觉，是本书最强盲区。
- 用户是单纯想做**组织心智诊断**（转 org-mind-diagnosis）或**老板四观自检**（转 boss-mind-fourviews）或 **BATA 养生经营边界**（转 bata-business-boundary）——本 skill 只管"教练能力地图"，不替这些 skill。
- 用户想把劳资矛盾（低薪/过劳/欠社保的正当诉求）用"心智不成熟/不同频"软化处理——这是 ce01/ce03 的 gaslighting 红线，转 value-business-hr 的劳工边界，本 skill 不参与。
- 纯知识问答、纯政策咨询、纯求职薪资数据查询。

### 作者在书中警告 / 批判阶段推导的失败模式

- **ce31 认证与招生招商深度交织（boundary-critical）**：认证方同时是教材方、考核方、复训收费方与"风口/蓝海"就业前景宣传方，四重角色重合，缺少外部评价与投诉渠道。证书仅体系内自证、外部无第三方效力；"中级即可独立开展个案"却面向非医学背景的六类人群，专业资质与执业风险不匹配。必须明示。
- **ce47 第一重"践行"无外部可观测指标、IAMS 两年一审形同自证（boundary-critical）**："践行"只能自陈（心得/日志），无行为化考核；复审由同一体系自审、伦理审查亦自我执行，质量闭环建立在"自己人审自己人"上。消费者难以分辨真能力，边界失效。
- **ce33 "得体的防御"高功能个案隐藏自伤信号（boundary-critical）**：体面、清晰、只谈 KPI 的来访者，风险不可见；"怕自己哪天会顶不住"是转介红线信号。不得只按点单服务（"我只要能睡好就行"），也不得过度反应强行戳破致脱落——平静追问、做风险评估、命中即转介。
- **ce34 企业付费个案的双委托方冲突（boundary-critical）**：付费方（公司）与对象（员工）诉求可能对立；事前未书面约定反馈口径，事后每一次索要个体反馈都是单方博弈，泄密即摧毁可信度并可能喂给"不同频请退"（ce03）。必须事前书面约定只报聚合数据。
- **ce36 自伤/他伤/精神障碍/器质病变转介红线（safety-critical）**：明确或暗示的自伤他伤（含"顶不住""不想醒来"）、幻觉妄想、疑似未诊断躯体疾病，必须中止服务启动转介。职场放大器：高功能来访者表达委婉（ce33）、企业采购又有"把人处理掉就算完成"的压力，红线更易被越过——因此必须写成硬性清单与本地应急电话，不能依赖判断。
- **ce37 擅自停药（referral-redline）**：书中软化条款（切勿停药、遵医嘱、BMC 为辅助）与替代性解释（停药反复=本原未修复）并存，足以诱导来访者自行减停。凡服精神科药物者，用药调整须遵医嘱，本 skill 不替代。
- **ce38 把案例效果类推到所有人（overclaiming）**：20 例自然样本无对照组、有选择偏倚，不得作为普遍疗效证据；禁用"治愈/根治/保证"等医疗诊断用语。

### 作者的盲点 / 时代局限

- **认证质量闭环存疑（ce47 延伸）**：收费认证缺乏独立第三方背书，"能力证明"与"付费续证"同源，审查激励偏向续费而非淘汰。使用本 skill 时须把"认证含金量"作为明示项，而非默认成立。
- **心智学 ≠ 医疗**：全书已立"不替代医疗、不擅自停药、见红旗即转介"（ce36–ce38，核心本已立），但本体论底色仍把抑郁解释为"觉识粒子缺失"、把停药反复归因为"本原未修复"，重性障碍仅以"转介"一笔带过。本 skill 必须显式声明：心智学是认知升级导向，非疗愈、非诊断、非医学。

### 容易混淆的邻近方法论

- **IAMS 认证 ≠ 国家/行业执业资格**：前者体系内自颁自审，后者有法定准入与监管。跨语境宣传"国际通用"却不具当地执业资质的，须提示风险。
- **企业心智教练 ≠ 普通企业教练(ECPC)/EAP 心理援助**：前者基于心智学体系（三重能力 + BMC），后者有独立资质体系；重叠在"服务企业"，差异在方法论与执业边界。
- **三重能力的"践行者" ≠ 上过课**：第一重是真实修识践行，无外部指标（ce47），因此不能以"持证/听课"替代，只能由用户诚实自评 + 第三重落地表现反推。
