# 原生家庭反驳框架（归因—受害 → 成长—建构）

## R — 原文 (Reading)

> "大多数心理困扰，本质上并不是'原生家庭'问题，而是个体的心智层级尚未完成相应成长与整合……从'归因—受害'模式到'成长—建构'路径的范式转向。"
>
> — 意师, 第六章 论文四

---

## I — 方法论骨架 (Interpretation)

这是一个反决定论框架：原生家庭**有影响，但非解释一切的终极原因**。它把心理困扰的三种误区——因果简化（"都是父母造成"）、责任外推（"所以我不用改"）、成长停滞（"注定了"）——转为一条建设性路径：

- **承认真实影响，但不固着受害者叙事**：家庭环境是起点之一，不是终点判决书。
- **评估焦点转移（p54）**：从"童年经历了什么"转向"面对这些经历，我的认知收获是什么、现在如何应对"；帮人描绘自己的心智运作模式（他人行为→我的解读→情绪→行为选择），而不是复述"外界如何对我不好"的故事。
- **从归因—受害到成长—建构（f14/p53）**：重心落在"我愿意把怎样的自己带向明天"，把能量从追责移向成长。

关键重定义：**反原生家庭决定论 ≠ 否定原生家庭、更≠否定真实创伤**。本书此立场有低估真实创伤持续影响之嫌（见 B 段），因此本 skill 强制保留创伤评估与专业转介入口——不可把反决定论滑向"全是自己责任"。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: "从小被忽视，亲密关系总搞砸，是童年注定吗？"（书中论文四推演 + p54）
- **问题**: 用户把反复失败的亲密关系完全归因"童年被忽视"，陷入"注定搞砸"的受害叙事，动弹不得。
- **方法论的使用**: 先承认真实成长环境的影响（不否认），再按 p54 把评估焦点从"童年经历了什么"转向"面对经历，我的认知收获与当下应对"；用"他人行为→我的解读→情绪→行为选择"描绘其关系中的心智运作模式，替代"父母害我"的单一故事。
- **结论**: 原生家庭是影响因素而非宿命；可问"我愿意把怎样的自己带向明天"重启成长责任。
- **结果**: 从"归因—受害"转向"成长—建构"，能量由追责移向可改变的当下应对。

### 案例 2: ce15 警示——真实创伤者被"二次否定"（书中边界反例）
- **问题**: 一位有童年虐待/依恋创伤史的来访者，被回应"别追责父母了，去成长吧"，创伤被轻描淡写。
- **方法论的使用**: 本书论文四"反原生家庭"若推向极端，会把复杂困境单因化为"你只是心智没成长"，对确有虐待史者形成二次否定，低估创伤持续影响（ce15）。
- **结论**: 反决定论不能变成"真实伤害不存在"。有真实创伤史者，必须先承认真实伤害、停止二次否定。
- **结果**: 本 skill 据此设置强制创伤评估与转介入口——此类情形不套用"成长—建构"话术，转介专业心理/精神帮助。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 反复说"我性格/问题都是小时候父母造成的"，把一切外推给原生家庭。
2. 亲密关系、职场受挫就归因童年，陷在受害者心态里难以行动。
3. 想从"追责父母"转向自我负责，但不知怎么转、怕变成自我苛责。
4. 看到"原生家庭决定论"内容，想辨别其合理边界。
5. 作为家长/疏导师，面对把问题全推给上一代的叙事，想温和转向成长。

### 语言信号 (用户的话里出现这些就应激活)

- "都是原生家庭害的 / 我性格都是小时候造成的"
- "童年注定了我 / 我改不了"
- "受害者心态 / 凭什么我要承担"
- "原生家庭决定论 / 归因—受害"
- "怎么从受害者转向成长 / 成长—建构"

### 与相邻 skill 的区分

- 与 `youth-issue-decode`（composes-with）的区别：youth-issue-decode 是青少年议题（手机PSU/厌学/空心病）的"心智学归因与处置"；本 skill 是更上游的**归因框架**——当用户把议题归咎"父母/童年"时，先用本 skill 完成归因转向，再视情况进入议题处置。
- 与 `bmc-youth-boundary`（联动边界）的区别：本 skill 是成长导向的归因重构，**非医疗**；一旦触达真实虐待/依恋创伤史、或重性障碍/自伤信号，立即转 bmc-youth-boundary 的专业转介边界，不可继续用"成长—建构"话术。
- 与 `growth-orientation-ai` 的区别：growth-orientation-ai 是"成长导向 vs 治疗导向"的总开关与 AI 时代回应；本 skill 是总开关在"原生家庭叙事"这一具体议题上的应用。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **先做一次创伤评估（强制，不可跳过）**
   - 完成标准: 询问是否有真实虐待、忽视、依恋创伤或持续伤害史；若有明确信号 → 跳到步骤 4（创伤转介），**不**套用"成长—建构"话术。
   - 判停条件: 出现自伤/他伤/重性障碍信号 → 立即转 `bmc-youth-boundary`。

2. **区分"影响"与"决定"**
   - 完成标准: 用一句话承认"原生家庭有影响"，再用一句话澄清"但不是宿命"；避免滑向"全是父母责任"或"全是自己责任"任一极端。

3. **做评估焦点转移**
   - 完成标准: 引导用户从"童年经历了什么"转向"面对经历，我的认知收获与当下应对"；共同描绘其心智运作模式（他人行为→我的解读→情绪→行为选择），替代"外界如何对我不好"的单一故事。

4. **创伤评估阳性 → 承认真实伤害并转介**
   - 完成标准: 明确告知"这不是你'没成长'，是真实发生的伤害"，停止二次否定；提供专业心理/精神帮助转介建议（见 B 段入口），不替代专业治疗。

5. **从归因—受害转向成长—建构**
   - 完成标准: 以"我愿意把怎样的自己带向明天"收尾，落在一个可行动的小改变上。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户有**真实虐待/依恋创伤史**却借此逃避承认伤害——本 skill 不用于"驳倒"受害者，而须先承认真实伤害并转介（见下）。
- 重性精神障碍、自伤/他伤风险——立即转 `bmc-youth-boundary`，非本 skill 范围。
- 把反决定论写成"全是自己责任""你只是心智没成长"的过度归因（这正是本书的立场盲点，须避免）。

### 创伤评估与专业转介入口（强制保留）

> **本书反原生家庭立场可能低估真实创伤（ce15 / BOOK_OVERVIEW §3 盲点3）。本 skill 严禁把反决定论变成对真实伤害的二次否定。**

- 若用户述及童年虐待、长期忽视、依恋创伤、暴力/性侵等真实伤害史：**先承认真实伤害存在**，不使用"别追责父母、去成长"等淡化话术；明确告知"这不是你心智没成长，是真实发生的伤害"。
- **转介建议**：建议其寻求专业心理/精神帮助（心理咨询师、精神科、创伤治疗资源、社会支持系统）；本 skill 与心智学**非医疗体系**，不替代、不延误专业治疗。
- 反复出现闪回、解离、严重依恋紊乱等，直接转 `bmc-youth-boundary` 的转介清单。

### 作者在书中警告的失败模式

- **反原生家庭矫枉过正（ce15）**：全盘否定原生家庭解释力，对确有创伤史者形成"你只是心智没成长"的二次否定，低估持续性影响。本 skill 的创伤评估入口即为此设。

### 作者的盲点 / 时代局限

- **反原生家庭矫枉过正**（BOOK_OVERVIEW §3 盲点3）：论文四几乎全盘否定原生家庭解释力，将"追责父母"等同于"受害心态"，可能低估真实童年创伤/依恋损伤的持续影响。本 skill 已用创伤转介入口对冲该盲点。
- **结构问题个体化**（盲点2）：把许多困境归因于个体"心智未完成成长"，弱化了家庭系统、代际创伤、社会结构等真实外部因素；承认影响≠否认结构，二者并存。
- 心智学**非医疗体系**：本 skill 是归因重构工具，不诊断、不治疗，不替代精神医学。

### 容易混淆的邻近方法论

- 与"原生家庭决定论"（"一切都是父母造成的"）相反；与"全盘否定原生家庭"（"童年不算什么"）也相反——本 skill 走中间：**承认影响、拒绝宿命、保留创伤转介**。
- 与"宽恕四前提"（核心本 g25）互补但不等同：成长—建构不要求原谅施害者；若对方不担责，"不宽恕"亦正当。
