# 心智层级自评与成长路径

## R — 原文 (Reading)

> 心智学将人类心智分为六个层级：儿童型、青年型、成人型、精英型、智者型、达者型。"心智层级"不是一个僵硬框架，而是一面镜子，一个指南针。自我定位、理解他人、指明路径。
>
> — 作者, 第二章 认知人类心智层级

> 心智层级、情感频率、人格成熟度，三者成正比相关。心智层级低，则情感频率低、人格成熟度低；心智层级高，则情感频率高、人格成熟度高。
>
> — 作者, 第五章 领悟心智层级与情感频率

---

## I — 方法论骨架 (Interpretation)

心智层级是一把可测、可训的"成长阶梯镜"，不是模糊的"成熟/幼稚"形容词。六层从低到高：儿童型(偏执任性)→青年型(冲动盲从)→成人型(稳重责任)→精英型(懂思考会倾听)→智者型(思维完善自我约束)→达者型(发现自我自我发现)。

它和"情感频率""人格成熟度"构成**三元正相关**——层级越高，三者同向越高，互为表征。

关键重定义：
- **成年≠成人**：生理成年但心智可能停滞在儿童型/青年型，这就是"成年幼稚病"，三特征是任性、盲从、偏执。
- **心智成熟三要素**：认知成熟度(事实vs观点、批判性思考)、情绪成熟度(不被情绪左右、建设性表达)、社交成熟度(从他人视角看问题、尊重规则与边界)。
- **成长路径**：从"归因-受害"模式转向"成长-建构"模式——问题根源不是"过去伤害了我"，而是"旧认知模式不足以支撑当下"。

层级与年龄、学历、履历无关，是成长阶段参考。

## A1 — 书中的应用 (Past Application)

### 案例 1: 日本社会"孤独死"折射社会心智危机
- **问题**: 日本社会长期面临"孤独死"问题，大量老人和年轻人缺乏人生价值感。
- **方法论的使用**: 用心智层级框架(镜子/指南针)诊断——高度发达表象之下，是个体"相处—自处"能力与自我回归期滞后，即社会层面的心智层级滞后。
- **结论**: 这是社会心智危机，而非单纯的孤独或经济问题。
- **结果**: 被纳入"现代孤独与相处自处能力重建"合作课题，拟以 BMC 与相处自处课程对比 UCLA 孤独量表。

### 案例 2: 美国年轻人焦虑抑郁攀升
- **问题**: 美国年轻一代焦虑症与抑郁症患病率持续攀升，传统干预方法未能有效解决。
- **方法论的使用**: 用心智层级框架重新定义——价值丧失与心智迷茫是表象，本质是心智层级滞后，而非单纯病理。
- **结论**: 需心智学介入(价值观重塑与层级提升)，而非仅医药/病理矫正。
- **结果**: 作为"心智学在情绪化时代应运而生"的时代证据，指向心智层级提升的必要性。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 自我怀疑："我是不是心智不成熟 / 太幼稚了"。
2. 评价他人："为什么 TA 这么幼稚 / 这人靠不靠谱"。
3. 反复受困："我总被困在同一个模式里 / 总遇到同一种人"。
4. 想规划自我成长路径：想知道自己卡在哪一阶、下一步怎么走。
5. 面对原生家庭叙事：想从"都是父母造成的"转向自我成长。

### 语言信号 (用户的话里出现这些就应激活)

- "我是不是心智不成熟 / 太幼稚了"
- "TA 太幼稚了 / 这人靠不靠谱"
- "我总在同一个坑里 / 为什么我总遇到这种人"
- "原生家庭造成的 / 我能做的有限"
- "我总是情绪化 / 一被否定就炸"

### 与相邻 skill 的区分

- 与 `benyuan-perspective`（depends-on，前置）的区别：benyuan-perspective 是**世界观前提**（这是表象还是本原、不贴标签不病理化、三项原则），不给层级结论；本 skill 是**定位镜**，给出"在第几层、下一步练什么"。前置关系体现在：层级只有在"反标签、成长导向、不当病治"的立场下才是成长阶段参考，否则六层级会立刻退化成新一轮标签（"你就是儿童型"）。用户说"我有病/都是原生家庭害的"时先调它校准，再进本 skill 定位。
- 与 `mind-revolution-toolkit`（composes-with）的区别：工具包是**认知工具箱**（具体怎么想、怎么破局），本 skill 是**定位镜/指南针**，偏诊断与路径。互补成闭环：本 skill 诊断出偏弱要素（认知/情绪/社交），工具包提供对应练习（拼板/去标签/四问法/置换），练完回本 skill 复测层级。
- 与 `bmc-integration`（composes-with）的区别：本 skill 是**普通人自评与成长定位**，不涉干预手法；BMC 是**从业者对个案的身心整合工作流**（面谈三原则、闭环三问、转介红黄牌）。配合方式：疏导师在 BMC 破象定位阶段用本 skill 给个案做层级判断，作为三环调配的依据；反过来，本 skill 一旦触发判停条件（自伤/幻觉/重性障碍信号），立即交由 BMC 的转介规则处置。注意方向别搞反——本 skill 是自评，不是让个案自测后自行干预。
- 与 `mind-tripod-principles`（三基石）/ `relation-three-principles`（关系三原则）的区别：那两者是**价值与关系处置原则**（该不该原谅、怎么相处），本 skill 只做**层级诊断与成长定位**，不给价值定性、不给沟通脚本。层级是三基石的前置（处世三原则是层级提升后的自然显现），但本 skill 不代它下判断。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **定位层级**
   - 完成标准: 用六层级镜对照自己/对方行为，给出当前所处层级(儿童/青年/成人/精英/智者/达者)及具体依据。

2. **三元印证**
   - 完成标准: 检查情感频率(同频/共振能力)与人格成熟度(认知/情绪/社交三要素)是否与层级一致，列出三者中偏弱的要素。

3. **排查成年幼稚病**
   - 完成标准: 对照任性/盲从/偏执三特征，标注是否存在及具体表现。
   - 判停条件: 若出现自伤/幻觉/重度精神障碍信号 → 立即转介 `bmc-integration`(C7/ce39)，停止自评。

4. **指路径**
   - 完成标准: 从"归因-受害"转向"成长-建构"，针对偏弱要素给 1–2 项可执行练习(如拼板、去标签、情绪省察)。

5. **收尾确认**
   - 完成标准: 用户能说出"我现在在第 X 层，下一步练 Y"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 医学/精神科诊断，或对重性精神障碍做归因（转介 C7/ce18/ce39）。
- 贴标签羞辱他人、纯性格点评、把层级当道德高低的人身攻击。
- 把一切归咎原生家庭（ce15），或滑向"全是自己责任"的过度归因。

### 作者在书中警告的失败模式

- **ce15 原生家庭决定论**：把复杂困扰单因化、宿命化为"原生家庭不好"，陷入受害者叙事、责任外推、成长停滞。
- **ce28 成年幼稚病**：任性(妄为、看不到反噬)→盲从(缺独立人格、反智)→偏执(固化认知、拒绝成长)，三者常并发。
- **ce16 心理学标签滥用**：用"高敏感/讨好型/原生家庭"把复杂困境简化为个人缺陷，成"精致逃避"。

### 作者的盲点 / 时代局限

- 测试仅作**教学参考、不可固化人**(p44/ce28)——层级是成长阶段参考，不是定终身的标签。
- 反对原生家庭决定论，但**不可滑向"全是自己责任"的过度归因**。
- 重性精神障碍**必须转介**(见 C7/ce18/ce39)，本 skill 非医疗。

### 容易混淆的邻近方法论

- 与"要成熟"式说教不同：层级可测可训、与年龄学历无关(p42)；成年≠成人；把心理困扰从"归因-受害"转为"成长-建构"是作者差异化框架，非普通"你该长大了"劝诫。

## 配套交互自评网页

本 skill 附带可交互自评网页 `mind-level-self-assessment.html`（纯前端、零依赖，本地双击即可运行）。激活本 skill 后，可直接让用户打开该网页完成自评。

- **题库机制（已升级）**：四个维度（认知成熟度 / 情绪成熟度 / 社交成熟度 / 成年幼稚病排查）各内置 **15 题题库池**，每次打开网页**随机抽取 5 题/维度**，共 **20 题**；题目不固定，可反复测、前后对照。
- **计分与输出**：网页自动计算三要素（认知/情绪/社交成熟度）均分，绘制四轴雷达图（认知/情绪/社交/幼稚特征），定位六层级（儿童/青年/成人/精英/智者/达者）并给出分层成长指引；另单列"成年幼稚病排查"维度（分高＝越有幼稚特征，需警惕）。
- **判定阈值（按心智学框架推导，待与书原文校准）**：综合分 =（认知+情绪+社交）/3，≥4.6 且情绪≥4.5 → 智者型；≥4.3 → 精英型；≥3.5 → 成人型；成年幼稚病维度均分 ≥3.5 时压低定位并提示优先觉察。
- 网页顶部已注明"成长阶段参考、不贴标签、不替代专业帮助"。
