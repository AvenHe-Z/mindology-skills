# C8 价值观商业诊断（一宗旨五要素 + 财富安全）

## R — 原文 (Reading)

> 价值观商业：一宗旨、五要素——是战略罗盘，也是实践基石。一宗旨：逆发展，顺平衡。五要素：从办公司到办量场；从造产品到造价值；从做经营到做平衡；从劳资双方到量场共识；从企业文化到价值观同频。
>
> — 《意·心智学》，第七章 第二节

> 增长悖论：财富与安全的「死亡曲线」……当财富规模达到某个「转折点」时，安全感不再上升。三个陷阱：把偶发当常态；把侥幸当能力；把变相当宽容。请把握六个字：「无安全，慎发展」。
>
> — 原则 p87，第七章 第三节

---

## I — 方法论骨架 (Interpretation)

这是一套把企业经营从「利益最大化」转向「平衡最大化」的诊断框架。它的起点是一个反直觉的宗旨——「逆发展·顺平衡」：逆发展是向外做减法（对盲目扩张主动刹车），顺平衡是向内做加法（顺应价值观内在秩序）。两者共同构成企业的压舱石。

落地靠「五要素」阶梯：从办公司→办量场（经营观）、造产品→造价值（产出观）、做经营→做平衡（平衡观）、劳资双方→量场共识（组织观）、企业文化→价值观同频（驱动观）。这五阶层层递进，既是战略罗盘，也是卡点定位器——企业卡在哪一级，就清楚下一步往哪跃迁。「平衡最大化」不等于「各方都不得罪」，而是综合利益最大化，拒绝以损害平衡换成功。

财富安全则用「死亡曲线」警示：财富与安全感并非正比，越过转折点后规模反而吞噬安全感；配套三陷阱（偶发当常态、侥幸当能力、放任当宽容）与决策原则「无安全，慎发展」。价值观本身不能自上而下「规定」，须自下而上由全员心智教育生成「意理念」，成为「能成为员工价值观的价值观」；否则只是褒义词堆砌的空洞口号，或靠涨薪股权维系的「逐利团伙」（以利诱之，利尽人散）。

## A1 — 书中的应用 (Past Application)

### 案例 1：某公司导入心智教育的组织反馈（c49）
- **问题**：企业希望改善人文环境与团队韧性，但此前价值观多为老板按需发布或外部策划堆砌，员工无内生认同。
- **方法论的使用**：公司导入心智教育（价值观商业落地），用「量场」「相处原则」等概念做全员内训，从「和稀泥」式管理转清晰，并依同频与否调整人员（补偿请退不同频者），把价值观作为自下而上的意理念生成。
- **结论**：价值观商业的威力不在口号，而在全员心智成长后的行为改变与量场共识。
- **结果**：八卦与负面情绪减少、团队更韧、运营成本降低、员工群策群力降本；新员工半月超越老员工、经理能对接大项目，团队向心力显著增强。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 企业家/高管做战略复盘，发现「越做越大却越心慌」「增长没带来安全感」。
2. 团队留不住人、核心层动荡，怀疑是文化或价值观问题而非单纯薪酬。
3. 墙上的价值观没人信、老板自己也不践行，想搞清楚为什么空洞。
4. 盲目扩张或面临冒进决策，需要「该不该继续做大」的判断框架。
5. 绩效管理走极端（大锅饭或末位淘汰），或组织被「逐利团伙」逻辑主导。

### 语言信号 (用户的话里出现这些就应激活)

- 「越做大越心慌 / 增长没带来安全感 / 钱越多越怕出事」
- 「团队留不住人 / 价值观墙上的字没人信 / 老板说一套做一套」
- 「要不要继续扩张 / 我们现在卡在哪一步」
- 「绩效怎么考才不伤团队 / 怎么让价值观真落地」
- "values business / balanced maximization / wealth safety death curve / top-down vs bottom-up values"

### 与相邻 skill 的区分

- 与 `mind-tripod-principles`（depends-on，前置）的区别：三基石是**通用价值判据**（平衡/情感/控制 + 尊重/宽容/谦和），本技能把它在企业经营中**场景化**为一宗旨五要素与财富安全，聚焦组织诊断。前置关系体现在：本技能的两个核心结论都直接建立在三基石对「平衡」的定义之上——「顺平衡/平衡最大化」若按常识理解成"平均、妥协、各方都不得罪"就会全盘走偏（三基石明确平衡=对系统规律的顺势遵循、有度、反贪妄）；「发展崇拜、把侥幸当能力」的识别则依赖三基石的"贪妄两副面孔"。此外「自下而上生成价值观」的前提是"企业家先自成长"，即老板本人先过三基石的自我检核。尺度不同：三基石的对象是"我和某个人/某件事"，本技能的对象是"组织与量场"。
- 与 `relation-three-principles`（关系三原则）的区别：关系原则讲**个人相处**（互敬/边界/自敛、沟通脚本）；本技能讲**「企业量场」内劳资/团队的共识与边界**，尺度在组织而非个人。老板与某个下属的具体冲突转关系三原则，"团队为什么留不住人、价值观为什么没人信"用本技能。
- 与 `mind-level-self-assess`（心智层级自评）的区别：本技能诊断**组织**的价值观健康度，层级自评诊断**个人**心智层级——但二者互为底层：作者认为组织价值观空洞的根因常是企业家个人心智层级滞后，因此本技能给出"企业家先自成长"结论时，通常需要个人层级自评配套落地。
- 与 `benyuan-perspective` 的区别：它是全体系的世界观前提（反标签、三项原则），本技能是最末端的场景应用。注意本技能 B 段已声明"逆发展·顺平衡"属强反叙事，须按三项原则做条件化理解、结合真实市场约束，不作经营唯一真理。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **用五要素阶梯定位卡点**
   - 完成标准：针对「办公司/办量场、造产品/造价值、做经营/做平衡、劳资/量场共识、文化/价值观同频」逐项问用户「你目前在哪一阶」，输出一个明确的卡点阶梯图（如「还在造产品、未到造价值」）。

2. **核对一宗旨：逆发展·顺平衡**
   - 完成标准：判断企业是否陷入「发展崇拜/盲目扩张」(ce30)；若扩张已伤害量场存续或心智不足以驾驭变量，给出「逆发展」刹车建议，并明确「平衡最大化≠利益最大化」(p85)。

3. **做财富安全体检：死亡曲线 + 三陷阱**
   - 完成标准：列出当前规模相对「安全感转折点」的位置；逐条排查三陷阱——偶发当常态？侥幸当能力？放任当宽容？(ce31/ce32)；输出「无安全，慎发展」的判定与下一步节奏建议。

4. **诊断价值观生成路径**
   - 完成标准：判断企业价值观是「自上而下规定」还是「自下而上吸纳」(p82/f36)；是否空洞口号(ce36)或「逐利团伙」(ce37)；给出「企业家先自成长、全员心智教育生成意理念」的落地方向，并核对绩效管理是否避开两极端(ce33/ce35, p88)。

5. **收束为可行动诊断报告**
   - 完成标准：给出「卡点 + 逆/顺建议 + 财富安全判定 + 价值观落地动作」四块结论，每条指向具体下一阶跃迁动作，而非抽象告诫。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **纯技术操作问题**：财务建模、税务、法务合规、具体融资条款等——这些不是价值观/心智层面的卡点，本技能不替代专业顾问。
- **个人投资理财建议**：死亡曲线是企业家心智盲区框架，不是个股/理财建议。
- **已确认外部硬约束**：若困境纯属市场、政策、资金链等外部因素，应先解决硬约束，本技能只补心智/价值观视角。

### 作者在书中警告的失败模式

- 发展崇拜/盲目扩张 (ce30)：规模越大越激进，心智不足以应对系统变量即崩盘。
- 财富=安全错觉 (ce31)：误以为「做大才能抗风险」，转折点后变量激增反噬安全感。
- 三陷阱 (ce32)：把偶发当常态（豪赌）、把侥幸当能力（傲慢）、把放任当宽容（侵蚀秩序）。
- 绩效两极端 (ce33/ce35)：一碗水端平养懒人、末位淘汰造恐惧，均破坏平衡 (p88)。
- 价值观=褒义词堆砌 (ce36)：老板发布/策划公司打造，沦为空洞口号。
- 逐利团伙 (ce37)：靠涨薪股权维系，以利诱之、利尽人散 (p100)。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- 「逆发展·顺平衡」「平衡最大化」是对主流「股东利益最大化」的强反叙事，作为世界观前提有启发，但直接套用可能弱化对增长、竞争、资本效率的现实考量；本技能将其定位为「诊断视角」而非经营唯一真理，使用者须结合真实市场约束。

### 容易混淆的邻近方法论

- 不要把「平衡最大化」误读为「平均/妥协/各方都不得罪」——它是综合利益最大化且拒绝损害平衡换成功 (p85)。
- 不要把「自下而上价值观」误读为「员工说了算」——前提是企业家先自成长、全员经心智教育生成意理念 (p82/p89)。
