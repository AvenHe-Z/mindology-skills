# 组织心智诊断与护城河 + 双向奔赴组织变革（组织变革总纲）

## R — 原文 (Reading)

> "企业是个组织，组织心智层级，由其中个体心智汇聚。企业的'组织心智'就像一条'看不见的护城河'。组织心智高的企业，韧性更强；反之易在风浪中消耗、内部撕扯。护城河深浅，由成人型心智占比决定。"
>
> — 意师, 第六章 第一节（三）组织心智

> "企业心智教育必须是一场双向奔赴。员工成长，企业有执行基础；老板成长，企业有方向基础；员工与老板共同成长，企业才有价值观基础，这正是'价值观商业'的起点。"
>
> — 意师, 第六章 第二节（五）双向奔赴

> "把企业家从焦虑的'问题解决者'，转变为从容的'量场维系者'——守护组织量场而非灭火。"
>
> — 意师, 第六章 第三节（词汇 g14 量场维系者）

---

## I — 方法论骨架 (Interpretation)

这是组织层面的"心智聚合 + 变革"总框架，把《职场心智学》第六章零散的两条线收口：

**1. 组织心智护城河（聚合论 / f01·p47·g01）**
组织不是抽象文化，而是内部每个成员心智层级的"加总"。个体心智越成熟（尤其成人型心智占比越高），协同、创造、抗风险的自驱力越强——这是一条不写在报表上、却决定企业能扛多大风浪的"护城河"。难点在于它无现成度量工具，诊断必须靠结构+心智双清单并行，不能只排课。

**2. 双向奔赴组织变革（f23·p61）**
组织变革不是单向"管员工"，而是员工侧（提供执行基础）与老板侧（提供方向基础）共同成长。员工心智不成熟=内耗，老板心智不成熟=系统性风险，二者并行才长出价值观基础。企业家的最终角色是升维为"量场维系者"（g14）：从灭火者变守护者。

**3. 心智教育导入经营（附录四模块）**
把心智教育落到 HR/经营的四个动作：招聘看价值观同频度、绩效做平衡考核、培训以心智教育为核心、员工心智管理自下而上。

**差异化之处**：本框架最大价值是"成人型心智占比=护城河"的聚合视角 + 双向奔赴变革 + 量场维系者角色；但**它必须同时扛住劳工与结构性红线**——心智教育不能替代制度修复、不能软化劳资冲突、不能变成单方面压员工的软性管控。这也是它作为"组织变革总纲"串联 C4（老板心智四观）与 C6（价值观商业 HR 落地）的位置所在。

## A1 — 书中的应用 (Past Application)

### 案例 1: 某企业导入心智教育的真实反馈（c05）

- **问题**: 某匿名企业导入心智教育后，原以为"人性化管理=无规则无边界"，组织内耗、沟通成本高、运营成本压不下来。
- **方法论的使用**: 用组织心智护城河视角复盘——识别此前"无规则=人性"的误区，把管理从和稀泥改为"人与事分离、岗位第一责任人制"；案例中对企业认为"价值观确实不同频者"采取了**主动补偿请退**。**⚠️ 立场对齐（与 value-business-hr 一致）**：本 skill **不采纳"补偿请退"这一动作**（ce03/ce45，亦是全书最可操作也最危险的一条）——它理由不可核验、不可申辩，最先被判"不同频"的往往是提异议/追问薪酬/拒加班者；"主动补偿"只处理金钱、不制约判断权滥用，不能替代程序正当性。处理不胜任须回归**可举证的岗位胜任力标准**，不可用主观频率判断代替。其余组织变革成效（规则立起、员工主动降本）仍成立，但须剥离"补偿请退"这一危险动作。员工开始主动思考降本（水电/采购/餐厅）。
- **结论**: 沟通成本、内耗、运营成本同步下降，团队向心力与方向感上升。
- **结果**: 新人半月超老员工、杨经理对接大项目带团队——组织心智提升外化为执行力。

### 案例 2: "是公司让我来的"——企业付费员工被迫疏导（c07）

- **问题**: 员工一坐下就说"我没什么问题，是公司让我来的，你尽管走流程吧"，主动性为零；付费方（公司）与个案（员工）诉求可能冲突。
- **方法论的使用**: 心智教育必须"自下而上"——员工侧没有共同语言与切身收益，任何新理念都会变成又一轮运动。疏导师同时面对两个委托方，须事前书面约定反馈口径（只回报聚合数据）。
- **结论**: 强行走完流程=合规表演；零主动性个案应"不强求不放弃"，判断继续还是体面终止。
- **结果**: 书中未给结论，指向"员工心智管理自下而上"与保密/双委托方冲突的处理框架（见 ce34）。

### 案例 3（反例红线束）: 劳资矛盾被软化 + 用心智替代制度（ce01 + ce12）

- **问题**: 跨部门协作反复失败，HR 想排"心智课"；同时员工关于低薪/过劳/欠社保的诉求被回应为"你的心智层级问题/不同频"。
- **方法论的使用**（作者用作反证）: 凡组织症状都还原为成员心智（ce12 还原论）——但同一问题换过三批人仍复发，说明病因在权责设计、考核冲突、信息割裂，不在人。更危险的是把结构性对立在定义层面取消（"没有劳资双方只有伙伴"）来拒绝协商（ce01 gaslighting）。
- **结论**: 只排课忽略结构→预测复发；把正当诉求转译为人格缺陷→形成 gaslighting 闭环。
- **结果**: 员工越申诉越"证明"自己心智不成熟，劳动法通道被替换。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 跨部门协作反复失败、内耗严重，想做组织诊断或排心智课。
2. 企业想导入心智教育/价值观同频，不知从招聘、绩效、培训还是员工侧切入。
3. 创始人/老板想做组织变革，但不确定是"只打动自己"还是"员工老板两侧同走"。
4. 评估一家企业的韧性/护城河——"为什么同样的风浪，有的公司散了有的扛住了"。
5. HR/OD 做组织心智健康度盘点，需要一套结构+心智双清单。
6. 有人把"不同频/量场共识"用在谈薪、谈工时、谈安全的冲突上（→本 skill 须识别为红线并拒绝，转劳动权益框架）。

### 语言信号 (用户的话里出现这些就应激活)

- "我们组织心智/团队心智不行 org-mind is low"
- "怎么评估公司的护城河/成人型心智占比 moat / adult-mind ratio"
- "想做双向奔赴/员工和老板一起成长 dual-growth"
- "我是量场维系者/想把老板升维成守护者 field-keeper"
- "怎么把心智教育导入经营 mind-education import"
- "价值观不同频/量场共识" 被用在劳资、薪酬、安全、解雇语境（→ 红线激活，见 B 段）

### 与相邻 skill 的区分

- **本 skill 是"组织变革总纲"**：站在组织层，把 C4（老板心智四观）与 C6（价值观商业 HR 落地）串起来。它不是单点工具，而是定位"先诊断组织、再决定往哪侧排课"的总入口。
- 与 `boss-mind-fourviews`（composes-with）的区别：本 skill 看"组织作为聚合体"的健康度；boss-mind-fourviews 看"老板这一个源头变量"的四观（利益/员工/风险/价值观）。当诊断落点在老板心智时，交给 boss-mind-fourviews 做四观自检——它是本 skill 的源头侧补丁。
- 与 `value-business-hr`（composes-with）的区别：本 skill 给组织诊断+双向奔赴框架；value-business-hr 落到 HR 四模块与一宗旨五要素的卡点阶梯诊断。组织盘点出结构问题后，由 value-business-hr 接具体落地方案。
- 与 `corp-mind-coach`（composes-with）的区别：corp-mind-coach 是"企业心智教练"的从业者能力地图与双委托方/保密红线；本 skill 是客户侧/组织侧的诊断工具。教练进场前，用本 skill 做组织心智诊断；教练的保密冲突（ce34）两者共享。
- 与 `bata-business-boundary`（composes-with）的区别：bata 是 B 端养生商业化（含安全/招商红线）；本 skill 是组织心智与变革。两者仅在"企业付费场景双委托方保密"上交叉（ce34）。
- 与 `workplace-pua-guard`、`workplace-competent-selfassess`、`origin-family-bias-break`：这些都是个体/双人层 skill，本 skill 在它们之上做组织聚合，不替代其个体处置。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **红线预筛（必须最先做，不可跳过）**
   - 完成标准: 确认进来的是"组织诊断/变革"而非"用心智话术处理劳资冲突"。若用户的诉求本质是低薪/过劳/不安全/欠社保等正当权益，且被措辞成"不同频/量场共识/心智不成熟" → **立即拒绝软化，保留劳动权益 framing，建议走劳动法/集体协商通道**（ce01）。若"价值观不同频"正被用于解雇/劝退且无行为事实 → 标注 ce03 红线。
   - 判停条件: 命中任一 gaslighting/软性管控信号 → 不继续做组织诊断美化，先还原为结构/权益议题。

2. **成人型心智占比评估（聚合诊断）**
   - 完成标准: 用六层级（儿童/青年/成人/精英/智者/达者，g01 引用）对组织做分布估算——问"这组织的成人型心智占比大致多少、谁在拖累、谁在托底"，并明确标注这是**教学性估算、无硬度量、不作人事标签**（ce35）。

3. **护城河健康度体检**
   - 完成标准: 从三问判断组织护城河深浅：①危机时是否自驱而非互撕？②跨团队协作靠约定还是靠救火？③老板侧与员工侧的心智是否同步。逐条给"强/中/弱"判定。

4. **结构 / 心智双清单（关键，防 ce12）**
   - 完成标准: 同一问题必须同时产出 A. 结构性建议（权责设计、考核冲突、信息割裂、汇报链）与 B. 心智侧建议（排课/成熟度）。**诊断报告里一条结构性建议都没有=不合格**（ce12）。若同一问题换过三批人仍复发，病因锁定结构。

5. **双向奔赴变革自检（防 ce02/ce22）**
   - 完成标准: 检查变革是否**两侧同时排课**——员工侧 + 老板侧都有课，且员工侧有可见的权益改善（对价：安全感/成长路径/合理报酬）。**只对员工排课（ce02 软性管控）或只打动企业家（ce22 无基础空转）均为失败形态**。输出"90 天量场维系者方案"雏形。

6. **复盘与收尾**
   - 完成标准: 约定复检口径——内耗是否下降、结构建议是否落地、护城河是否变深；用户能说出"这是结构病因 X 还是心智病因 Y，我下一步先做 Z"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill（或必须转换为拒绝对话）

- **ce01 劳资矛盾不得软化为"不同频/量场共识"（最强红线）**：低薪、过劳、不安全的工作条件、拖欠社保——这些是劳动者的正当诉求，是劳动法与集体协商的通道，不是心智问题。严禁用"没有劳资双方只有伙伴""你心智层级还没到"来拒绝协商或取消对立语言。诊断权掌握在付费方手里时，这种 softening 即 gaslighting。
- **ce02 心智教育不得沦为降低监管成本的软性管控**：若培训 KPI 写成"降低离职率/降低管理成本"而非"员工可自主行使的权利增加"，或只要求员工"自敛"而管理侧失序不进议题 → 这是单方面提高忍耐阈值的课程，拒绝以"组织心智"包装。
- **ce03 "价值观不同频"不得作不可核验的解雇/劝退理由**：无行为事实、只凭主观频率判断、且被请退者集中于提异议/追薪酬/拒加班的人 → 这是歧视与滥权风险，必须标注并建议回归可举证的胜任力标准。（本体系对此动作的完整拒纳理由与"补偿请退"为何危险，详见 `value-business-hr` 的 ce03/ce45 红线，两 skill 立场一致。）
- **ce12 不得用"提升心智"替代制度修复**：同问题换三批人仍复发=结构病因；诊断报告必须有结构性建议，且"组织心智提升"的证据不能是培训满意度。
- **ce22 变革须自下而上 + 两侧同时排课**：只打动企业家"自上而下"、员工侧无配套权益改善 = 无基础空转；只做员工层 = 软性管控。两侧必须并行。
- **ce34 企业付费场景保密失守（与 C9 共享）**：双委托方冲突——事前须书面约定反馈口径、只回报聚合数据；失守即摧毁可信度。对"是公司让我来的"个案不得强行走完流程。
- **ce35 六层级不得贴标签进人事**：心智六层级只用于自我照镜子，不得给同事/下属定级、不得进人事档案、不得作晋升/请退依据；作者"除非对方拒绝成长"的豁免口子禁止启用。
- **心智学非医疗、不替代医学/劳动法**：本 skill 是组织心智的诊断与变革框架，不诊断疾病、不开药、不替代劳动法律师或集体协商。涉及医学/工伤/违法用工，直接转介专业机构。

### 作者在书中警告的失败模式

- **ce11 "老板心智决定天花板"单因论**：不可把企业成败全归创始人心智，抹除行业周期/政策/资本/运气；对失败创业者是归因暴力（本 skill 诊断须保留结构变量）。
- **ce44 "逆发展·顺平衡"被老板当拒资话术**：平衡叙事只砍员工侧成本、不约束老板侧冒险 = 绿washing；本 skill 的护城河评估须双向。
- **ce45 用"频率/同频"做伪科学招聘/清洗**：不可观测、不可申诉=歧视风险；同频标准须成文、可量化、可异议。

### 作者的盲点 / 时代局限

- **组织心智的还原论（§3 未证假设3）**：模型只有"个体心智"一个自变量，结构/制度/权力分布无变量位置——凡模型看不见的，干预就不会发生。"看不见的护城河"无度量方法，投入效果不可验证（ce12）。
- **"没有劳资双方"取消对立语言（§3 立场盲点2 + 最强反对1）**：把结构性对立在定义层取消而非解决，弱势方失去描述处境的词汇、诊断权在付费方——这是本 skill 最重的 critique 红线，已在 ce01/ce43/ce48 强制绑定。
- **ROI 叙事天然指向最便宜路径（改造人而非改造制度，ce02）**：作者自己给了"减少监管成本"的 ROI，组织心智模型里制度无位置，二者叠加易滑向软性管控。

### 容易混淆的邻近方法论

- **组织心智 ≠ 企业文化/团队氛围（g01）**：前者是个体心智聚合的可诊断变量，后者常被当成宣导软指标。
- **双向奔赴 ≠ 只给员工上课（ce02/ce22）**：必须两侧排课 + 员工侧权益改善。
- **量场维系者 ≠ 救火队长/管理者（g14）**：前者守护量场健康，后者被动解决问题。
- **成人型心智占比 ≠ 人事分级工具（ce35）**：是组织级健康估算，不是给个人贴层级标签。
