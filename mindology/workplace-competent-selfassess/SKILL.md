# 合格职场人能力自评与提升（四能力 + 三维度）

## R — 原文 (Reading)

> "职场人应具备以下四种心智能力：第一，能承责。第二，能协作。第三，能自敛。第四，能成长。职场上，自己的心智层级，决定自己的职业上限。"
>
> — 意师, 第六章 第一节（三）

> "心智成熟有三个维度：1、认知成熟度……能摆脱反射思维；2、情绪成熟度……不被情绪左右；3、社交成熟度……懂得尊重规则和边界。这三维度不是一蹴而就。"
>
> — 意师, 第六章 第二节（二）

---

## I — 方法论骨架 (Interpretation)

这是一张"合格职场人"的自检尺，不评绩效、不评 KPI，只量**心智成熟度**。它由两个嵌套标尺构成：

**四能力（行为面）**
- **能承责**：直面后果、主动担责，不甩锅不缩头。
- **能协作**：在共同目标下找到自己的位置，不越界也不逃避。
- **能自敛**：知分寸界线——什么该争取、什么该放下，什么是原则、什么只是情绪。
- **能成长**：从挫折与错误里修识转化，而非重复同一反应。

**三维度（心智底层支撑）**
- **认知成熟度 = 摆脱反射思维**：遇到人遇事，先理解语境而非颅内条件反射；能区分事实与观点、能延迟满足。这是本书最反直觉的一点——"心智成熟"不是"想得深"，而是"不被本能反应牵着走"。
- **情绪成熟度**：不被情绪左右，能识别情绪来源、建设性表达。
- **社交成熟度**：从他人视角看问题，尊重规则与边界。

**两条必须强调的差异化洞见**
- **自敛 ≠ 怂 / 圆滑**：自敛是内在收敛、守自己边界的"言行缓冲带"，不是回避冲突、不是憋屈自己、不是无底线老好人。把边界当甩锅借口、或把沉默当美德，都不是自敛。
- **认知成熟 = 摆脱反射思维**：本书评估尺不是通用胜任力模型，而是用"能否跳出条件反射"来判定心智层级——同样的话，有人秒回情绪，有人先问"他说的是什么、我想的是什么"。

合格职场人模型见术语 g03（四能力 + 三维度），本 skill 不重定义该术语，只把它落成可填的自评表与练习。

## A1 — 书中的应用 (Past Application)

### 案例 1: 38 岁私营老板——第一次坦然拒绝订饭，边界重建（c04）

- **问题**: 女/38/私营老板，长期焦虑、委屈、恐惧，人际与亲子关系紧张；此前"总是不好意思拒绝"同事帮忙订饭，把委屈咽下去。
- **方法论的使用**: 在四能力里定位"能自敛"短板——不是不会拒绝，而是把"不好意思"误当成对他人的义务。疏导中她第一次坦然告诉同事"不需要帮我订饭"；一个月后反馈：原需一个月调整的情绪现在两三天自愈，与孩子的关系也缓和，不再自卑、开始喜欢自己。
- **结论**: "自敛"是可练习的——它把"守住自己边界"从道德负担变成日常动作，且边界稳了，情绪与关系反而松了。
- **结果**: 掌握情绪调节方法，人际/亲子改善，自我接纳提升——自敛落地带来的连锁正向变化。

### 案例 2（反例）: 伪谦和 / 无边界老好人（ce40）

- **问题**: 不适却笑着说"没关系、都可以、没事"，靠意志力维持"好相处"形象；被裹挟往不认同的方向走时选择沉默或附和。
- **方法论的使用**（作者用作反证）: 这恰是"自敛"被误读的形态——用"我比较随和"给回避表态、回避担责、怕冲突贴美德标签。真谦和是柔中有界、和而不随、善而不懦，是内在充盈的副产品；伪谦和是表演，装一天没事、一周累、一个月崩。
- **结论**: **没有边界的"老好人"不是成熟，是软弱**。自评时若"说没关系之后回家心里有事""他人反复试探你的底线却从未收到清晰信号"，那是伪谦和，不是能自敛。
- **结果**: 既无立场也无边界，被反复越界、被轻视——提醒本 skill 用户在填"能自敛"高分前先区分真自敛与伪谦和。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 想系统评估"我算不算合格/成熟职场人"，想找自己在承责、协作、边界、成长上的具体短板，而不是一句模糊的"我得提升"。
2. 常被评价"难合作""太玻璃心""不会拒绝"，自己也想分清：这是能力缺口还是边界不清、还是被误读。
3. 高绩效但拒绝跨团队协调、把边界当甩锅借口，想确认"这到底卡在哪一层"。
4. 带团队/做管理，想用同一把尺给下属做成长对话，而非直接扣绩效。
5. 纠结"自敛 vs 怂 / 谦和 vs 老好人"——不知道自己是不是在过度忍让。

### 语言信号 (用户的话里出现这些就应激活)

- "我是不是合格/成熟职场人 / 怎么自评自己"
- "总是被说难合作 / 太玻璃心 / how to assess if I'm a qualified worker"
- "我不想承责吗 / 还是他们权责不清"
- "自敛还是怂 / 我是不是太好说话了 / self-restraint or just spineless"
- "能承责能协作 / can I take responsibility and collaborate"
- "边界到底在哪 / boundary of accountability"

### 与相邻 skill 的区分

- 与 `workplace-relation-rebuild`（composes-with）的区别：本 skill 面向**个人自检与补强**（四能力+三维度自评表），只处理"我"的能力画像；workplace-relation-rebuild 处理**上下级/同事/客户五重构 + 四边界**的具体关系操作话术。顺序：先用本 skill 定位"我在协作/边界上缺哪块"，再转 relation-rebuild 拿具体重构清单。
- 与 `boss-mind-fourviews`（composes-with）的区别：boss-mind-fourviews 是从**利益/员工/风险/价值观四观**诊断**老板心智**这个源头变量；本 skill 是诊断**个体员工/职场人自身**的合格度。老板自评四观 → boss-mind-fourviews；普通职场人自评四能力 → 本 skill。
- 与 `org-mind-diagnosis`（composes-with）的区别：org-mind-diagnosis 看**组织心智护城河、成人型心智占比**等聚合变量；本 skill 看**个体**。个体自评发现多人同缺口时，提示可能是结构/组织问题，转 org-mind-diagnosis。
- 与 `workplace-pua-guard`（contrasts-with，跨 skill 诱饵）的区别：若用户描述的是"上级贬低/冷暴力/精神控制让我怀疑自己"，那是 **PUA 识别与拿回判断力**，应触发 workplace-pua-guard，**不应**用本 skill 把它读成"你的心智层级不够、该自敛"。本 skill 严格禁止把受害体验重述为个人不成熟（ce04/ce43）。
- 与 `origin-family-bias-break`（contrasts-with）的区别：若用户把职场困境全归因于童年/父母，那是原生家庭偏差破除，转 origin-family-bias-break；本 skill 只在"如何修正当下"层面用，不处理归因叙事。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **红线预筛（必须最先做，不可跳过）**
   - 完成标准: 确认用户描述的是**自我能力缺口**，而非结构性不公（权责不清/KPI 不合理/报酬不公/上级越界）或精神控制（PUA）。若命中结构或 PUA 信号 → 停止用"个人心智不成熟"框架，转对应 skill（ce04/ce43）。
   - 判停条件: 出现自伤/他伤意图、幻觉妄想、明显精神障碍信号 → 立即转介专业机构，心智学不替代医学（ce36–ce38）。

2. **填四能力自评表**
   - 完成标准: 对"能承责 / 能协作 / 能自敛 / 能成长"四项各打 1–5 分，并各写一句近期具体事例支撑（避免空打）。区分真自敛与伪谦和（ce40）：若"能自敛"高分但伴随"回家心里有事/被反复试探底线无信号"，判为伪谦和、实际低分。

3. **用三维度定位缺口层级**
   - 完成标准: 把四能力短板映射到三维度——承责/协作弱多在**社交成熟度**；情绪化、易被激在**情绪成熟度**；秒回反射、不分事实观点在**认知成熟度（未摆脱反射思维）**。得出"我主要卡在哪一维度"的单一结论。

4. **生成补强练习（按缺口给 1–2 项）**
   - 完成标准: 社交成熟度缺口 → 给"在共同目标下定义你的协作边界"练习；认知成熟度缺口 → 给"遇事先问'他说的是什么、我想的是什么'"的反射思维阻断练习；能自敛缺口 → 给"本周一次坦然说'不'/表达异议"的最小必要表达练习（非甩锅、非回避）。

5. **复检与收尾**
   - 完成标准: 约定 1–2 周后复检——四项分数是否有依据地变化、是否出现新的结构/PUA 信号。用户能说出"我不再把 X 当成 Y，这周先做 Z"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **结构性问题被个体化（ce04，强制红线）**：管理失当、权责不清、KPI 不合理、上级越界、报酬不公等，先排除结构成因。**不得把管理失当/权责不清统一读成"个人心智不成熟"**——给受害者上课、给制造问题者免责是诊断错误。同一岗位连续多人出现同一症状，仍按个案心智处理，即触发此红线。
- **贴标签 / 进人事考评（ce35，强制红线）**：六层级与四能力/三维度**只用于自我照镜子**。不得贴同事/下属"儿童型心智"标签，不得作晋升/请退依据，不得进人事档案。作者留的"除非拒绝成长"豁免口子**禁止启用**——任何情形下不得据此给他人定性。
- **"自敛"被挪用为封口工具（ce43，强制红线）**：自敛是双向的（敬人所以知界、守界所以自敛），在权力不对称中不得被压扁为单向——只要求下属对越界安排、不合理指令、PUA 沉默吞下。若"你一表达异议，对方便回'你要学会自敛'"，这不是自敛、是 gaslighting，本 skill 不为此背书。
- **伪谦和不是成熟（ce40）**：无边界老好人、用"随和"回避担责，不是能自敛；自评时须剔除这类假性高分。
- 医学/精神障碍、自伤他伤、幻觉妄想：心智学不是医疗诊断，不替代医学评估与治疗；正在服药者切勿据本 skill 建议停减药（ce36–ce38）。

### 作者在书中警告的失败模式

- **ce04 结构问题个体化**：把"动不动想离职""永远跟领导较劲"一律读作个体心智滞后，跳过管理失当/权责不清的第二种解释，干预方向整体偏移。
- **ce35 层级贴标签**：六层级从自省工具转用为给他人分级，形成更具"科学"外观、更难反驳的组织内贬损标签。
- **ce43 自敛封口**：边界原则被上级反向挪用为要求下属吞下越界、噤声服从的规训工具。
- **ce40 伪谦和**：把回避表态、回避担责、怕冲突包装成美德，最终既无立场也无边界。

### 作者的盲点 / 时代局限

- **结构问题个体化倾向（§3 盲点2）**：本书总纲"所谓心理问题本质都是心智问题"外推到组织层面易变单因论——所有组织症状还原为成员心智，与作者批判心理学"滥贴标签"同构。本 skill 以 ce04 红线强制先排结构。
- **反医学底色虽软化仍存（ce36–ce38）**：本书已明确"不替代医疗、遵医嘱"，但仍把抑郁解释为"觉识粒子缺失"，重性障碍仅以"转介"带过。**心智学不是医疗诊断，不替代任何医学评估与治疗。**

### 容易混淆的邻近方法论

- **自敛 ≠ 怂/圆滑/老好人**（p19/ce40）：自敛是言行的"缓冲带"、守界而非回避；怂是憋屈、老好人是无边界表演。
- **认知成熟 ≠ 想得深**（f03）：是"摆脱反射思维"——不被关键词点燃、先理解语境。
- **本 skill ≠ 绩效考核**（g03）：四能力是心智口径的成长清单，不是 KPI 达标表；不得与人事决策挂钩（ce35）。
- **本 skill ≠ PUA 处置**：被上级精神控制时，问题在与对方的越界，不在你的心智层级（ce43/ce04），应转 workplace-pua-guard。

- **文件**: `workplace-competent-selfassess.html`（与本 SKILL.md 同目录，可由助手直接打开）
- **用法**: 纯前端、零依赖、无外部 CDN，本地双击浏览器打开即用；答完点"看我的能力画像"，结果区动态生成（四能力分卡 + SVG 手绘雷达图 + 三维度定位 + 补强练习）。可反复重测做 1–2 周复检。
