# BMC 青少年应用与转介边界（从业者专用）

## R — 原文 (Reading)

> "正在接受药物治疗的个案，切勿擅自停药或减药。BMC意识强化与医学治疗并不冲突，可以作为辅助手段协同进行。具体用药调整，须遵医嘱。"
>
> — 意师, 第三章·BMC意识强化

---

## I — 方法论骨架 (Interpretation)

本技能是**从业者护栏**，不是操作手册。它把青少年 BMC 应用锁死在三条不可让步的边界上：

1. **药物边界**：正在服药的青少年来访者，BMC 仅作辅助，切勿擅自停药/减药，用药调整须遵医嘱；"药只是压症状、BMC能去根"是危险叙事。
2. **转介边界**：一旦出现自伤/他伤风险、精神障碍疑似（幻觉妄想）、器质性病变可能，必须立即中止服务、启动转介；重性精神障碍/急性自杀风险/严重成瘾须转精神科、临床医学与社会支持系统。
3. **测评边界**：五层心智、情感频率、四无筛查等结果**仅作成长参考，不作临床诊断标签**，不得给孩子定性"新星级/病态"。

**BMC 身体调理的 hands-on 手法不进入本纯文本技能**——任何按压/调理/手法描述全部剔除，只保留"身心修复→转介"的原则叙事；具体手法须由具备线下带教资质的从业者执行。未成年人个案须监护人知情同意。本技能的定位是"非医疗、高风险即转介"，书中学说底色（如"觉识粒子缺失""停药反复=本原未修复"）在红线下一律让位。

## A1 — 书中的应用 (Past Application)

### 案例 1：四年级东东——睡眠与学习修复（c10，仅作"身心修复→转介"叙事）
- **问题**：四年级东东长期睡眠不佳→大脑反应迟钝→学习效率低→厌学情绪；家长欲通过 BMC 身体调理改善。
- **方法论的使用**：本书记录 BMC 介入后入睡变快、睡眠加深、白天精力改善，印证"身体调理是身心康复之本"。本技能**仅保留这一修复叙事**，已剔除原文所有手法描述（如"手法放松脑区、触发副交感优位"）；并明确：该案例须监护人知情同意，且若东东伴自伤/幻觉/神经认知损伤等证据，必须立即转介而非继续调理。
- **结论**：生理状态改善可为认知提升增效，但 BMC 始终是非医疗辅助，且本书不提供可纯文本交付的手法。
- **结果**：作为"身心修复→转介"叙事示例，强化本技能红线——手法剔除、未成年须同意、高风险即转介。

### 案例 2：抑郁服药青少年来做 BMC，"能停他的药吗"（verified C9·V2）
- **问题**：一名正在服用抗抑郁药、确诊抑郁的青少年来访者，家属问"做 BMC 能不能停他的药"。
- **方法论的使用**：依 p44 切勿擅自停药、BMC 仅辅助；依 p45/ce01 出现精神病性症状或急性风险须立即中止转介；依 ce02"药只是压症状、BMC能去根"属延误治疗风险，明确反对；依 ce18 测评结果不可当诊断标签。
- **结论**：BMC 与医学治疗协同而非替代；任何"停药/用 BMC 去根"的表述都越过红线。
- **结果**：明确"药不能停、BMC 只辅助、须遵医嘱"，并把该来访者维持在精神科随访框架内，未越界处置。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 从业者在给青少年来访者做 BMC 身心整合前，需要标准边界清单与中止/转介流程。
2. 来访者或家属问"能不能停药/减药、靠 BMC 行不行"。
3. 从业者识别出高风险信号（自伤/幻觉/重性障碍/严重成瘾），需立即转介。
4. 从业者想把五层/情感频率/四无测评结果当诊断标签给孩子定性——本技能叫停。
5. 非从业者（家长/教师）误以为本技能可给具体手法或医疗建议——本技能引导其转 youth-issue-decode / four-wu-screen。

### 语言信号（用户的话里出现这些就应激活）

- "这孩子做 BMC 能不能把药停了 / 不吃药靠这个行不行"
- "调理了好几次没变化，是不是方法有问题 / 该转哪"
- "孩子说不想活了 / 看到不存在的东西 / 砸东西伤人"
- "测评出来他是新星级/病态，是不是没救了"
- "BMC youth boundary / no-stop-medication / must refer out"

### 与相邻 skill 的区分

- 与 `bmc-integration`（depends-on，核心本）的区别：核心本 bmc-integration 是成人 BMC 三环工作流与转介边界；本技能是它的**青少年专用护栏叠加层**——额外强化"未成年须监护人知情同意、切勿擅自停药、测评不标签、重性障碍即转介"。前置关系：凡涉及青少年，先调本技能（更严），再承核心本工作流；本技能只可比核心本更严、不可更松。
- 与 `youth-issue-decode`（composes-with，C3）的区别：C3 是青少年议题（手机/厌学/叛逆/空心病）的心智学归因与处置；本技能是**从业者对来访者的安全边界**。配合方式：C3 遇高风险信号（自伤/幻觉/重性障碍）立即转本技能的红黄牌转介规则；本技能不替代 C3 的议题处置。
- 与 `four-wu-screen` / `growth-orientation-ai`（branch-skill）的区别：那两个是成长筛查与范式视角；本技能是**不可让步的从业者红线**，任何成长视角在红线下一律让位。

## E — 可执行步骤 (Execution)

> 本技能**不含任何身体调理 hands-on 手法**；如个案需要身体调理，须由具备线下带教资质的从业者执行，本文件仅以原则叙事引用之。

当 skill 被激活后，agent 应按以下步骤执行：

1. **用药与同意核查**
   - 完成标准：确认来访者是否正在服药（抗抑郁/情绪稳定/精神类）；若服药，明确"切勿擅自停药减药、BMC仅辅助、用药调整遵医嘱"；确认未成年人已获监护人知情同意。
   - 判停条件：若家属主动要求减停医嘱药物，或出现"药只是压症状、BMC能去根"表述 → 立即引用 ce02 红线，制止并维持医学随访。

2. **高风险红线扫描（每次服务必做）**
   - 完成标准：逐条核对 ce01/p45 清单——自伤/他伤风险、幻觉妄想等精神病性症状、明显神经认知损伤、急性自杀风险、严重成瘾、器质性病变、重性精神障碍（抑郁伴自伤/双相/精神分裂等）。
   - 判停条件：命中任一条 → 立即跳到步骤 4（中止并转介），不在本技能内继续任何调理或成长引导。

3. **测评结果使用边界**
   - 完成标准：五层/情感频率/四无等结果仅作成长参考，向用户说明"不作临床诊断标签、不给孩子定性"，不得出现"新星级/病态"式定性（ce18）。
   - 反例判定：连续两次会面诉求相关行为无任何积极变化甚至负向增加 → 视为反例，启动策略调整或重新评估，不得无效重复、不得越界承诺。

4. **中止与转介**
   - 完成标准：凡命中医学/法律/公共安全风险，明确告知"本书非医疗、BMC不替代药物或医学评估"，建议立即联系精神科/儿科/相关机构；同时禁用禁忌用语（见 B 段）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill（强边界，不可让步）

- **出现高风险信号时**：自伤/自杀意念、他伤风险、幻觉、妄想、明显神经认知损伤、严重成瘾、器质性病变、重性精神障碍（抑郁伴自伤/双相/精神分裂等）——立即中止服务、转介专业医疗/精神科/儿科，BMC 不得替代药物或医学评估（p45/ce01/ce17）。
- **需要具体身体调理手法时**：本技能剔除一切 hands-on 手法描述（c10 手法已全部删除，仅留"身心修复→转介"叙事）；手法无法纯文本准确交付且易过度承诺，须线下带教资质者执行。
- **未成年人个案**：须监护人知情同意，避免夸大表述（p98 精神）。
- **用户要求"治愈/根治/保证"时**：属越界承诺，本技能禁用。

### 作者在书中警告的失败模式（禁忌用语 ce38 同源）

- **绝对禁用语**：治愈、根治、包好、手到病除、保证/100%、极端表述、医疗诊断用语。本书**绝不**宣称治愈/根治/100%有效。
- **反模式 ce02「以药为敌」**：宣称"不吃药、靠 BMC 修复粒子可替代治疗"属延误正规治疗风险，本技能明确反对——切勿擅自停药、BMC 仅辅助、遵医嘱。
- **反模式 ce01「重性误读为滞后」**：把重性精神障碍/自杀自伤归为"心智层级低/成长慢"仅用 BMC 处置，延误诊断。
- **反模式 ce18「测评标签化」**：把教学测评当临床诊断给孩子定性。

### 作者的盲点 / 时代局限（来自阶段 0 批判）

- 本书把抑郁归因于"觉识粒子缺失"、将停药反复归因于"本原未修复"，在免责声明下仍可能延误正规治疗；重性状况仅"转介"一笔带过——故本技能把"高风险立即转介 + 非医疗定位"写死为不可让步边界，而非书中学说优先。
- 发育神经科学被工具化（前额叶未熟仅作"需 BMC 调理"铺垫），未纳入神经发育成熟时间窗；本书引用主流医学数据却又批判其范式，论证根基有裂缝。

### 容易混淆的邻近方法论

- 不要把"意识强化"误读为宗教/灵修/灵魂学（术语规范：灵格是工作性定义，非超自然）。
- 不要把"BMC 仅辅助"误读为"可替代药物"——辅助≠替代，用药调整一律遵医嘱。
- **心智学不构成医疗诊断、不替代医学、高风险转介**：本技能是从业者安全护栏，任何成长/调理视角在红线下一律让位专业医疗。
