# 青少年五层心智能力测试与成长指引

## R — 原文 (Reading)

> "我们将10岁至20岁青少年心智成长划分为五个层级：新星级、潜力级、铜牌级、银牌级、金牌级。对应不同的心智成长阶段，每个层级配有一套专属测试题，帮助青少年在心智教育进程中进行评估。"
>
> — 作者, 第二章第三节 青少年五层心智测试

> "心智层级与生理年龄并非正相关。一个12岁孩子可能具备银牌级心智，一个18岁青年也可能处于新星级。测试的意义不在于'贴标签'，而在于'照镜子'。"
>
> — 作者, 第二章第三节 / 第四章附录

---

## I — 方法论骨架 (Interpretation)

青少年五层心智模型把核心本的成人"六层级"重构为面向 10–20 岁的专属阶梯：新星级（发现情绪与规则）→潜力级（学会换位思考）→铜牌级（自我独立判断）→银牌级（思维成长与责任担当）→金牌级（自我省察与价值认知）。它不是能力定级，而是一面"成长镜子"和一张"路标地图"。

每层级配一套 10 题自评（A–D = 1–4 分，满分 40），测后给分层成长指引：新星级/潜力级从"摆脱反射思维"入手，铜牌级练"拼板置换"，银牌级修"情绪省察期/自我回归期"，金牌级走向"价值重塑"。

最关键的重定义：心智层级与生理年龄、性别、学历无关（p58），一个 12 岁孩子可能已是银牌级，一个 18 岁青年也可能停在新星级。测试的意义是"照镜子"而非"贴标签"，是成长阶段坐标而非终身判词。

---

## A1 — 书中的应用 (Past Application)

### 案例 1: iPad风波——心智层级测评环节的情绪失控
- **问题**: 男孩在五层心智测评环节因被指出表达不够严谨，面子上过不去，转而向妹妹索要 iPad，争执升级至踢人砸物、情绪完全失控。
- **方法论的使用**: 用五层模型作"镜子"而非"判词"——先分开保护、允许释放情绪，家长记录其"情绪省察期/自我回归期"数据；平复后用行为描述法引导其复述事件，对照所在层级的成长路标（情绪觉察与责任担当）。
- **结论**: 他的爆发不是"坏孩子"，而是所在层级在"情绪省察"维度尚需成长；测评的价值是照出下一步练什么，而非定性。
- **结果**: 男孩情绪恢复后表达清晰简练、互动笑声不断；复盘认识到"在情绪里的人没有理性"，并看见执着 iPad 背后是对"被区别对待"的真实需求。

### 案例 2: 17岁高三男生的高考焦虑
- **问题**: 17 岁男生将成绩与自我价值绑定，导致严重焦虑、考试发挥失常。
- **方法论的使用**: 用五层模型定位——其"自我省察与价值认知"（金牌级标志）尚未达成，自我价值仍外挂于分数；按分层指引走"独立思考、量力而为"的成长路径，而非归因为"心态差"。
- **结论**: 焦虑本质是价值认知未独立，属可训练的成长缺口，而非病症。
- **结果**: 学会身心放松、找到适合自己的备考节奏，焦虑明显缓解，核心收获是"要有独立思考，量力而为"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家长想了解孩子"心智到哪一层、与同龄人比怎样"。
2. 青少年想自评"我该怎么往上走"。
3. 出现"12岁比18岁侄子还懂事""大人了还不懂事"这类年龄与成熟度错位的困惑。
4. 想拿到分层、可执行的成长指引而非笼统评价。

### 语言信号 (用户的话里出现这些就应激活)

- "孩子不懂事/跟同龄人差一截"
- "想测测孩子心智到哪层"
- "怎么帮孩子往上走"
- "12岁比18岁还懂事正常吗"

### 与相邻 skill 的区分

- 与 `youth-emotion-frequency-test`（composes-with）的区别：本 skill 定位"五层心智层级"，C2 测"情感频率五项形状"，二者叠加成"心智层级×情感频率"综合画像（f23）；本 skill 答"在第几层"，C2 答"情绪关系哪块偏科"。
- 与 `youth-issue-decode`（contrasts-with）的区别：本 skill 只做层级定位与成长指引，不给议题（手机/厌学/叛逆）处置方案；遇到具体议题需转 C3。
- 与核心本 `mind-level-self-assess`（contrasts-with）的区别：核心本是成人六层级（含成年幼稚病诊断），本 skill 是 10–20 岁专属五层重构，去掉成年维度、突出可量化成长台阶，与年龄无关（p58）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **定位层级**
   - 完成标准: 引导用户按"最近三个月真实状态"完成五层各随机抽 5 题（共 25 题）的自评网页（或口述关键行为），对照五层模型给出当前所处层级（新星级/潜力级/铜牌级/银牌级/金牌级）及具体行为依据。

2. **年龄脱敏对照**
   - 完成标准: 明确告知心智层级与生理年龄无关（p58），用"照镜子"语言呈现，避免年龄比较与贴标签。
   - 判停条件: 若出现自伤/幻觉/重性障碍信号 → 立即转介精神科/儿科，停止自评（见 B 段医疗边界）。

3. **给出分层成长指引**
   - 完成标准: 按所在层级给 1–2 项可执行练习（新星级/潜力级→摆脱反射思维；铜牌级→拼板置换；银牌级→情绪省察期/自我回归期；金牌级→价值重塑）。

4. **收尾确认**
   - 完成标准: 用户能说出"我现在在第 X 层，下一步练 Y"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 医学/精神科诊断，或对重性精神障碍做归因（转介 `bmc-youth-boundary` / 精神科）。
- 贴标签羞辱、按年龄/学历给人定性（"你就是新星级"式人身攻击）。
- 把一切困境单因化为"心智层级低"，忽略教育制度、同辈竞争、资源不平等等结构因素（见 BOOK_OVERVIEW §3 立场盲点2）。

### 作者在书中警告的失败模式

- **ce18 测评误用/标签化**: 把五层测试结果当"诊断"或给孩子贴层级标签，固化认知、延误医学介入。
- **p58 照镜子非贴标签**: 测试意义在于照镜子而非贴标签，切勿固化人。

### 作者的盲点 / 时代局限

- 五层↔六层映射未经验证（BOOK_OVERVIEW §3 未证假设6）：新星级≈儿童型？金牌级≈成人型？仅是类比断言。
- 发育神经科学被工具化（§3 时代局限3）：把前额叶未熟等仅当"需 BMC 调理"铺垫，未纳入自然成熟时间窗。
- 反对意见指出：把发育性表现重新标签为"心智层级低"可能制造新病耻感（最强反对2）。

### 容易混淆的邻近方法论

- 与"成熟/不成熟"模糊形容词不同：五层是可测可训的成长阶梯，与年龄无关（p58）。
- 与核心本成人六层级不同：本 skill 是青少年专属五层重构，不含成年幼稚病诊断。

### 医疗边界（强制）

心智学不构成医疗诊断、不替代医学。重性精神障碍、急性自伤/自杀风险、器质性病变、严重成瘾必须转介专业医疗（精神科/儿科）。本测评结果只作成长参考，不作临床诊断、不贴标签。

## 配套交互自评网页

- **文件名**：`youth-mind-level-test.html`（与本 SKILL.md 同目录，纯前端、零依赖、无外部 CDN，可本地双击打开）。
- **用法**：浏览器打开后按"最近三个月真实状态"逐题自评（1=几乎不符合 … 5=非常符合），点「算我的心智层级」即出五层均分、雷达图与所在层级；「重置」可重测。
- **题库机制（已升级）**：五层（新星级/潜力级/铜牌级/银牌级/金牌级）各内置 **15 题题库池**，每次打开**随机抽取 5 题/层**，共 **25 题**；题目不固定，可反复测。
- **题目与逻辑**：每题描述该层典型行为。计分取每层均分（1–5）；**定位逻辑**：某层均分 ≥3.5 视为"达标"，从新星级往上找最高达标层即当前层级，一旦某层未达标则停在该层之下。
- **立场声明**：网页顶部含照镜子非贴标签、结果仅作成长参考、心智学不替代医疗、出现自伤/幻觉/重性障碍等高风险信号立即转介专业医疗/儿科；并含"年龄脱敏"提示（p58）。
