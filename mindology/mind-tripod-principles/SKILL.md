# 意理念三基石（平衡·情感·控制）+ 处世三原则

## R — 原文 (Reading)

> "平衡、情感、控制"称为"意理念三基石"。三者之间，也是一个动态平衡体系，三基石的"再平衡"。
> 意理念的"尊重"：对异己异见的心境，对弱者弱势的态度。"宽容"是宽恕、包容的动态统一。"谦和"源自成长，由内而外的善意、平和与从容，柔中有界、和而不随、善而不懦。
> 宽恕四前提：承认事实、承担责任、接受反噬、接受审核。

— 《意·心智学 1.4版》，第二章 心智开启·第3、6、7、8课

---

## I — 方法论骨架 (Interpretation)

本技能是做"价值判断与为人处世"的检核尺，分两层。

第一层是**意理念三基石**——价值观重塑的三根支柱，且需持续"再平衡"：
- **平衡**不是平均、折中、制衡或"我强了我掌控你"，而是对系统规律的顺势遵循，且有"显性功利贪"与"隐性高尚贪（以善为名）"两副面孔；
- **情感**是生命本质属性，要防"煽情"（把情感当工具操控他人）与"滥情"（忽视自身界线、迷失自我）；
- **控制**是对自身低频（贪妄、冲动）的省察调适，即"自我平衡"，而非对外操控他人。

第二层是**处世三原则**（心智成熟后自然显现，非外部规训）：
- **尊重**=对异己异见与弱势的心境，非对强势的敬畏/服从；
- **宽容**=宽恕+包容的动态统一，须过"宽恕四前提"否则是愚善纵容，不宽恕亦正当；
- **谦和**=由内而外的从容，柔中有界、和而不随、善而不懦，非表演或讨好。

收口处还有两条：**基础价值观≠普世价值**（前者源于灵格的先天跨文化共识，自内而外；后者是人格群体的文化输出）；**善恶以平衡判据**——维系平衡为善，妄为平衡为恶（含"以善为名"的隐性贪妄实为恶）。这一先天跨文化共识天然包容**跨地域、跨信仰、跨文化**的差异：基础价值观不绑定特定宗教或族群，故在多元社会里可作共同底线，而非某种文化的输出本身。

## A1 — 书中的应用 (Past Application)

### 案例 1：圣诞母女"置换"体验——真尊重宽容须进入他者条件
- **问题**：学员常把"尊重/宽容/谦和"当作空泛社交技巧，难以落地。
- **方法论的使用**：书中用圣诞逛街母女视角差异演示——妈妈看橱窗烟花愉悦，5岁女儿因身高只看到行色匆匆的腿、枯叶（c37）。说明环境/视角不同认知迥异，须进入他者条件才给得出真尊重与宽容。
- **结论**：尊重宽容谦和不是口号，而是需认知支撑（如置换）的修养。
- **结果**：学员理解"置换是探究对方观点的前置条件，而非简单换位思考"，三项处世原则由此变得可操作。

### 案例 2：借钱不还的"宽容"推演（宽恕四前提核查）
- **问题**：朋友反复借钱却不还，"我宽容是善良吗？"
- **方法论的使用**：经宽恕四前提核查——承认事实✓，但承担责任✗、接受反噬✗、接受审核✗，属愚善纵容（ce04）；同时识别"以善为名"的自我损耗与可能的伪谦和（ce05/ce06）。
- **结论**：这不是宽容而是纵容，应止付并设立边界，而非无条件放过。
- **结果**：把模糊的"原谅"变成可核验的流程，避免廉价原谅与道德绑架。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 纠结"这事算不算好心办坏事""我是不是在干涉/以善为名控制别人"——做价值判断时。
2. 纠结"该不该原谅TA""我是不是太宽容/太忍了让对方得寸进尺"——涉及宽恕时。
3. 想弄清"怎么才算真正的尊重/谦和"，分不清自己是在尊重、讨好还是压抑。
4. 迷茫"我的价值观是什么""基础价值观和普世价值/别人灌输的价值观有什么区别"。
5. 需要在伦理/善恶上快速判断（如政策、组织、个人行为的"善/恶"定性）。

- "这算不算好心办坏事""我是不是管太多了"
- "该不该原谅TA""我太宽容了是不是傻""不原谅是不是太小气"

### 与相邻 skill 的区分

- 与 `mind-level-self-assess`（depends-on，前置）的区别：层级自评回答"我在哪一层、下一步练什么"，本技能回答"这件事该怎么定性、我该不该原谅"。前置关系体现在：作者明确处世三原则（尊重/宽容/谦和）是**心智层级提升后自然显现的修养，而非靠意志力执行的规训**——所以对一个仍卡在儿童型/青年型（任性/盲从/偏执）的人，直接要求"你要宽容"只会变成压抑或表演。用户不清楚自己所处层级时，先用层级自评定位，再用本技能做价值检核。
- 与 `relation-three-principles`（composes-with）的区别：本技能偏**自我价值锚定与善恶判断**（"我该怎么判断/我是什么样的人"），关系三原则偏**相处自处与冲突沟通**（"我们怎么相处/冲突怎么处理"）。配合链路：本技能先定性（这是纵容还是宽容、对方是否过了宽恕四前提），关系三原则再落地（怎么开口、边界怎么设、最小必要回应怎么说）。纠结"该不该原谅"用本技能，纠结"一吵架就失控怎么沟通"用关系三原则。
- 与 `value-business-diagnose`（composes-with）的区别：本技能是**个人/通用价值判据**，商业诊断是它在**企业经营场景的放大版**——"平衡"变成"逆发展·顺平衡"与"平衡最大化"，"贪妄"变成"发展崇拜/侥幸当能力"。尺度不同：本技能的对象是"我和某个人/某件事"，它的对象是"组织与量场"。企业家问"我该不该继续扩张"用商业诊断，问"我这样对下属算不算以善为名的控制"用本技能。
- 与 `mind-revolution-toolkit` 的区别：那是认知升级工具（怎么想清楚），本技能是价值维度的**结论性检核**（想清楚之后该如何定性）。事实没还原清楚时先用工具包拼板/去标签，再回本技能下判断。
- 与 `emotion-frequency-decode` 的区别：情感频率是亲密关系的情感解构（同频/共振/是不是真爱），本技能的"情感"是三基石之一，重在**防煽情（把情感当工具操控他人）/防滥情（丧失自身界线）**的伦理检核，不判别"爱不爱"。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **锚定冲突点，先还原事实**
   - 用"录像机式"客观陈述（发生了什么、听到了什么）替代形容词与评判，回答"这是平衡还是失衡？事实是什么？"
   - 完成标准：用户能写出一句无主观评判的事实描述（对应 p70/ce24）。

2. **三基石再平衡检核**
   - 平衡：是否平均化/以强凌弱/隐性高尚贪（以善为名干涉）？情感：是否煽情/滥情？控制：是否在操控他人而非自我平衡？
   - 完成标准：三条各给出"失衡/平衡"判定及一句依据。

3. **处世三原则 + 宽恕四前提**
   - 若涉及原谅→走四前提（承认事实/承担责任/接受反噬/接受审核），缺一则"不宽恕正当"（p40）；
   - 若涉及尊重/谦和→检核是否伪谦和（社交表演/压抑）、是否单向服从（ce05/ce27）。
   - 完成标准：输出"是否宽恕/是否真尊重"的判定与前提核对表。
   - 判停条件：若用户流露重性情绪危机、自我伤害倾向 → 停止价值说教，转介（联动 C7/C6 边界）。

4. **善恶平衡收口与价值观校准**
   - 用"维系平衡=善/妄为平衡=恶"做定性；区分基础价值观（灵格先天、自内而外）与普世价值（人格文化输出）。
   - 完成标准：用户能陈述自己的底线价值观，以及本次判断所依据的三基石。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 纯信息查询、事实问答（不涉及价值判断）。
- 医疗、法律等专业诊断；对方为重性精神障碍、需临床干预时——本技能非医疗，须转介（联动 C7 / ce18 / ce39）。
- 用户只是想要"道德审判他人"的武器——本技能用于自我检核，非强加于人。

### 作者在书中警告的失败模式

- ce04 把宽容当纵容/愚善（无底线原谅，助长偏执）。
- ce05 伪谦和/社交表演（被要求的谦和=自我压抑）。
- ce06 以爱为名的管控/高尚隐性贪（"我是为你好"式越界）。
- ce07 煽情（把情感当工具操控）；ce08 滥情（忽视自身界线、丧失自我）。
- ce09 试图控制他人（把能量耗散在不可控外部）。
- ce10 把平衡误解为平均/制衡/以强凌弱。
- ce11 "万物一体/天下大同"式消除差异（以"大爱"抹杀个体边界）。

### 作者的盲点 / 时代局限

- 本技能的"灵格/基础价值观"本体论立场（先天跨文化共识）不可证伪，其跨文化"普世性"存哲学争议（阶段 0 批判：价值观具相对性）。使用时作为**个人价值校准工具**而非客观真理宣示。
- 勿将"不宽恕正当""基础价值观"当作居高临下的道德优越感来源。

### 容易混淆的邻近方法论

- 与普通"宽容是美德""尊重就是礼貌"混淆：本书定义差异见 glossary g25（宽容=宽恕四前提）、g28（尊重=对异己异见与弱势）。
- 与 C4 关系三原则混淆：C3 重"我该如何判断价值"，C4 重"我们如何相处"。
