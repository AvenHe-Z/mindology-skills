# 原生家庭思维偏差破除（成长者叙事，带创伤红线）

## R — 原文 (Reading)

> "（一）'原生家庭'概念的思维偏差：1、单因论（把所有复杂问题压缩到一个成因）；2、标签化（给整个家庭贴上'有毒家庭、控制型母亲、缺位父亲'等标签）；3、宿命论（把童年经历视为终身无法改变的印记）；4、受害心态（通过指认父母的不足，获得某种道德上的优势感）；5、责任外推（因为'是原生家庭造成的'，所以'我能做的很有限'）。"
>
> — 意师, 第六章 第一节（一）

> "每次被批评，都想到'我妈以前也这样对我'；每次拒绝不了越界请求，都用'我从小就被教育要听话'；每次跳槽，上面的悲剧换个地方再次上演。"
>
> — 意师, 第六章 第一节（二）职场悲剧循环

> "心智成长的第一步——是从'受害者叙事'走向'成长者叙事'。职场，不是无限承接个人伤口的地方。"
>
> — 意师, 第六章 第一节

---

## I — 方法论骨架 (Interpretation)

这是一张"归因纠偏"转译表：把用户口中的五类原生家庭归因，先点名为可识别的思维偏差，再换成一套把主动权交回当下的动作。

**五类可识别偏差（g06 / f07 / p41）**

- **单因论**：把复杂职场困境（协作失败、被批评、晋升无望）压缩到"因为我爸/我妈"这一个成因。
- **标签化**：给家庭整体贴"有毒家庭/控制型母亲/缺位父亲"的标签，用标签结束思考。
- **宿命论**：把童年经历看作终身印记，"我改不了，我从小就这样"。
- **受害心态**：通过指认父母不足获得道德优势感，叙事停在自己是无辜受害者。
- **责任外推**：因为"是原生家庭造成的"，所以"我能做的很有限"——把可改变的当下变量搁置。

**职场悲剧循环（f08 / p43）**：被批评→童年投射、拒越界→"从小被教育听话"、与上级摩擦→权威投射回避、错失机会→"没人教我争取"、跳槽→悲剧重演。核心是成年人在公司以儿童视角处事，换公司只换布景、剧本不变。

**成长者叙事改写（p42）**：决定未来的不是过去发生了什么，而是如何修正现在、承担未来；职场是社会交换场、心智检验场，不是疗愈地。

**最高优先级的一条不是改写，而是"何时不许改写"**：只要出现真实虐待/忽视/长期贬损史，叙事改写必须让位给创伤评估与转介（见 B 段 ce05）。偏差是"归因动作"的警示，绝不否定原生家庭影响的客观存在（ce06）。

## A1 — 书中的应用 (Past Application)

### 案例 1: 原生家庭归因的职场悲剧循环（c08）

- **问题**: 作者归类"原生家庭思维偏差五类型"后，给出五类职场悲剧循环——被批评即想到"我妈以前也这样对我"然后情绪上头；拒绝不了越界请求就用"我从小就被教育要听话"自我安慰。
- **方法论的使用**: 把每次挫折的第一反应点名为具体偏差（受害心态+责任外推），再指出其在职场的行为循环（童年投射、权威投射回避、跳槽重演）。
- **结论**: 主张从"受害者叙事"走向"成长者叙事"——过去≠未来，职场不是承接个人伤口之地。
- **结果**: 把"原生家庭"从情绪宣泄变为可诊断偏差，并指向当下可改变的变量。

### 案例 2: 59 岁退休财务的家庭—职场边界（c17）

- **问题**: 女儿二胎需帮忙、北方父母需照顾，两头操心、因相处问题常有负面情绪，并伴耳石症头晕、乳腺疼痛。
- **方法论的使用**: 书中将其置于"原生家庭思维偏差（家庭—职场边界）"框架下，分两次疏导（健康+相处），帮其区分"我能做的"与"我替不了谁的"。
- **结论**: 家庭责任与个人边界、身体信号交织时，先理清"可改的当下反应"而非外推责任。
- **结果**: 一周后耳石好转、两月后情绪稳定、乳腺不适几乎消失——作为家庭—身心交织的疏导范例（注意：本 skill 不含 BMC 手法，仅取"边界区分"思路）。

### 案例 3（反例 / 红线）: 真实创伤被二次否定（ce05）

- **问题**: 有来访者存在躯体虐待、性侵或长期羞辱史，应激反应被一律判为"受害心态/责任外推"。
- **方法论的使用**（作者用作需补的开关）: 书中把批评从"滥用"平移到了"归因本身"，缺少区分"叙事性逃避"与"真实创伤后遗"的开关。
- **结论**: 对真实创伤者只做"成长者叙事改写"= 二次伤害，会让需要创伤取向专业帮助的人错过转介。
- **结果**: 这就是本 skill 的红线——见 B 段 ce05，转介优先于改写。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 每次受挫第一句话都指向童年/父母，把职场冲突解释为"原生家庭害的"。
2. 用"有毒家庭""缺位父亲"等标签结束思考，不再往下看当下可改的变量。
3. 以受害者口吻外推责任："是原生家庭造成的，我能做的很有限"。
4. 跳槽换了好几家公司，却总遇到"一样的老板/一样的剧本"，反复重演同一类冲突。
5. 被批评就情绪上头、拒绝不了越界请求、与上级摩擦就回避——以儿童视角处事。

### 语言信号 (用户的话里出现这些就应激活, 中英双写)

- "原生家庭害我 / 我爸从小否定我 / family ruined me / my father always put me down"
- "我从小就这样 / 我改不了 / since childhood I'm like this / I can't change"
- "不是我的错 / 都是他们造成的 / it's not my fault / it's all because of them"
- "每次跳槽都一样 / 换公司还是遇到同样的人 / same loop after job-hopping"
- "我从小被教育要听话 / 拒绝不了越界请求 / I was taught to obey"

### 与相邻 skill 的区分

- 与 `workplace-pua-guard`（composes-with）的区别：**归因对象不同**。本 skill 面向"把困境归因于原生家庭/父母"的自我解释；workplace-pua-guard 面向"上级正在用贬低、冷暴力做精神控制"的外部侵害。当用户说"领导天天羞辱我、我是不是被 PUA"→ 走 workplace-pua-guard；当用户说"我领导跟我爸一样、都是原生家庭的错"→ 走本 skill（且若同时有虐待史，先按 ce05 转介）。
- 与 `workplace-competent-selfassess`（composes-with）的区别：那是"四能力+三维度"的**职场成熟度自评与补强**，不触碰原生家庭归因；本 skill 专攻"原生家庭归因偏差破除"。当用户问"我承责/协作能力怎么打分"→ workplace-competent-selfassess；当用户说"我承不了责是因为我爸从来没教过我"→ 本 skill（把归因偏差点出来，再联动自评）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **创伤红线预筛（必须最先做，不可跳过）**
   - 完成标准: 明确询问并确认是否存在——躯体虐待/性侵/长期贬损或忽视史、自伤或他伤意图、幻觉妄想等精神症状、近期急性躯体病。
   - 判停条件: 命中任意一项 → **立即停止叙事改写**，明确告知需创伤/精神科/医学专业评估，给出转介方向（可联动 workplace-pua-guard 若同时存在精神控制），并说明"这不是你心智没成长"（ce05）。本 skill 到此移交，不再进入步骤 2–4。

2. **五类型识别卡（对照自检）**
   - 完成标准: 让用户把最近一次职场受挫的第一反应，对照 g06 五类逐条点名——是单因论？标签化？宿命论？受害心态？还是责任外推？能说出"我刚才那句话落在第几类"。
   - 完成标准（补充）: 强调这五类是对"归因动作"的警示，不否定原生家庭影响的客观存在（ce06）。

3. **受害者→成长者改写练习**
   - 完成标准: 把一句受害者叙事改写为成长者叙事。模板：把"因为 X（童年/父母），所以我 Y（现在无能/无责）"改写为"过去 X 存在，但今天我可以做的第一步是 Z"。
   - 完成标准（补充）: 每句改写都能指出一个**当下可改变的变量**（沟通方式、边界表达、技能补齐、换岗），而非把"解释"当"解决"（ce06）。

4. **职场悲剧循环识别**
   - 完成标准: 引导用户记录"三份以上工作中反复出现的同一类冲突/同一离职理由"，点出这是以儿童视角处事、剧本重演（f08/ce07）；提醒 ce07——此循环用于**识别儿童视角、而非指责**。
   - 判停条件: 若用户出现真实创伤信号（回顾中情绪崩溃、提及虐待史）→ 回步骤 1。

5. **收尾与转介开关**
   - 完成标准: 用户能说出"这件事我不再只当成原生家庭的错，而是当成 X 偏差，我这周先做 Z"；并被告知：若改写后仍伴失眠/信心崩塌/功能持续恶化，或任何红线信号重现，立即转介专业，不迭代归因。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill（创伤转介红线，最高优先级）

- **ce05 真实虐待/长期贬损史者，禁止只做"成长者叙事改写"替代创伤评估与转介**：这是二次伤害红线。凡出现虐待/忽视/长期羞辱史，立即转介创伤取向专业帮助，不判"心智没成长"；"心智成长"不得用于替代创伤评估与转介。
- 已确诊或高度疑似精神障碍、出现自伤/他伤意念或行为、幻觉妄想等精神病性症状：立即转介精神科/医学，不做任何"归因偏差"解释。
- 存在真实外部侵害（如正在发生的职场 PUA、家暴、霸凌）：先处理安全与保护，转 workplace-pua-guard；不可把侵害重述为"你心智没成长"。
- 确属管理失当、权责不清、KPI 不合理、报酬不公等结构问题：先归责结构（对照 ce04），不可统一读作"个人心智不成熟"。

### 作者在书中警告的失败模式

- **ce05 反原生家庭矫枉过正、真实创伤被二次否定（本 skill 最危险）**：把批评从"滥用归因"平移到"归因本身"，缺少区分"叙事性逃避"与"真实创伤后遗"的开关。结果：对真实创伤者判"受害心态/责任外推"=告诉对方"你的痛苦是心智没长大"，且让其错过转介。
- **ce06 五类偏差是"归因动作"的警示，不是否定原生家庭影响的存在**：不可因识别偏差而否认原生家庭真实影响的客观存在；偏差指向"当下可改变量被搁置"，而非"童年经历不存在"。
- **ce07 职场悲剧循环用于识别儿童视角，非指责**：循环框架旨在让人看见自己以儿童视角处事、剧本重演，不是道德审判"你活该/你幼稚"。
- **ce04 结构问题个体化**：同一岗位连续多人出现同一症状、或讨论中出现"这是他心智问题"即终止追问，都是把组织症状还原为成员心智——属本书同源盲区，本 skill 不用于此类场景。

### 作者的盲点 / 时代局限

- **缺转介开关（§3 批判推导）**：书中五类偏差全部指向"归因动作"，未给"真实创伤后遗"留分流口。本 skill 以步骤 1 的红线预筛强制补上这一开关。
- **反医学底色虽软化仍存**：本书已立"不替代医疗、不擅自停药、见红旗即转介"（ce36–ce38），但把抑郁解释为"觉识粒子缺失"、把停药反复归为"本原未修复"。**心智学非医疗、不作诊断、不替代心理治疗与医学评估**。

### 容易混淆的邻近方法论

- **五类偏差 ≠ 否定原生家庭影响**：偏差针对"归因动作"，原生家庭影响的客观性不在此列（ce06）。
- **受害者叙事 ≠ 真实受害经历**：改写针对"把一切外推的叙事习惯"，不否认真实的受害/受虐事实；后者须转介（ce05）。
- **职场悲剧循环 ≠ 指责**：用于识别儿童视角与剧本重演，不是"你活该"（ce07）。
- 与"多读书多疗愈"的泛泛建议不同：本 skill 给的是五类型对照卡 + 受害者→成长者改写模板 + 转介开关，且自带红线。
