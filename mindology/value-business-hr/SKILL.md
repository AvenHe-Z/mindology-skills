# 价值观商业落地与 HR 四模块（一宗旨五要素 · 卡点阶梯诊断 · 心智培训导入）

## R — 原文 (Reading)

> "五要素：1、从办公司到办量场；2、从造产品到造价值；3、从做经营到做平衡；4、从劳资双方到量场共识；5、从企业文化到价值观同频。……以上五要素，并非五个独立运营模块，而是层层递进、环环相扣的认知阶梯。请用'五要素框架'作为诊断工具，复盘你企业在哪个'阶梯'卡住了。"
>
> — 意师, 第六章 第三节（二）教学参考 / 课堂研讨（p54 / f14）

> "一宗旨：逆发展，顺平衡。'逆发展'是对盲目扩张的主动刹车；'顺平衡'是顺应企业价值观内在平衡。"
>
> — 意师, 第六章 第三节（p53）

> "企业完成'心智教育导入'的四个特征：1）以'平衡'为市场原则；2）以'量场存续'为经营诉求；3）以安全感为基础的达成感；4）跨国公司的'资本安全阀'。"
>
> — 意师, 第六章 第三节（一）你公司的"企业价值观"有价值吗（f10 / p51）

> "招聘管理（匹配度、价值观同频度）；绩效管理（平衡考核，考绩效也考是否符合价值观）；培训管理（心智教育为核心）；员工心智管理（自下而上）。……为什么不先培训企业家'自上而下'？因为'自上而下'没有员工基础，而没有基础的变革，通常会以失败告终。"
>
> — 意师, 附录 心智教育导入公司经营（f13 / p52 / ce22）

> "不客气地说，这类企业价值观就像'褒义词堆砌'，墙上挂得齐整，员工心里悬空，只是企业的'装修'。"
>
> — 意师, 第六章 第三节（一）（ce18）

## I — 方法论骨架 (Interpretation)

这套东西要解决的是一个很具体的尴尬：几乎每家公司都有价值观，几乎没有一家的价值观在关键时刻起过作用。作者的处理办法不是换一批更好的词，而是**把价值观拆成经营动作和人事机制，然后看它在哪一级断掉**。

**一宗旨：逆发展·顺平衡（p53）**
"逆发展"不是不发展，是对盲目扩张主动踩刹车——有所为有所不为的减法；"顺平衡"是顺应利益相关者、内外、长短期这三组平衡的加法。两者一体两面。**但这条宗旨在本书里没有适用条件，所以它是本 skill 最容易被滥用的一条，见 B 段 ce17/ce44。**

**五要素：一条认知阶梯，不是五个并列模块（p54 / f14）**
从办公司→办量场（经营观）、造产品→造价值（产出观）、做经营→做平衡（平衡观）、劳资双方→量场共识（组织观）、企业文化→价值观同频（驱动观）。关键在"层层递进"：第 4 级的量场共识不可能建在第 3 级"只看利润不做平衡"的地基上。所以诊断方式是**自下而上找第一个断裂点**，而不是五项各打分求平均。

**四特征：判真伪的验尺（f10 / p51）**
真正完成心智教育导入的公司有四个可观察特征：以平衡（而非单方利益最大化）为市场原则；把量场存续当经营终极诉求；有以安全感为基础的达成感——**全员敢试错、敢说坏消息**，这是最硬的一条，也最难伪造；跨国经营时价值观充当"资本安全阀"（跨文化信任防线）。

**HR 四模块：把价值观变成可考核的机制（f13 / p52 / g12）**
招聘看价值观同频度（**必须成文、必须可举证，否则就是 ce45 歧视**）；绩效做平衡考核——既考业绩也考"这个业绩是怎么拿到的"，避免大锅饭与末位淘汰两个极端（ce19）；培训以认知/心智为核心，且晋升不搞"绩优则仕"、要有专业通道（ce20）；员工心智管理**自下而上**——先基层后老板，因为自上而下没有员工基础（ce22）。凝聚只靠钱与期权，养出来的是逐利团伙而非团队（ce21）。

**这个框架真正的差异不在"价值观很重要"这句话，而在两点**：一是它给出了一个**有顺序的诊断阶梯**（能回答"我卡在第几级"）；二是四个 HR 模块都是可以周一就动手改的东西。代价是：它的每一个抓手同时也是一把可以砸人的锤子——"同频"没有度量、"平衡"没有阈值，一旦进入人事权和预算权，就会回填为"老板是否喜欢你"。**所以本 skill 的正确形态是：诊断工具 + 三条不可越的红线，缺一不可。**

## A1 — 书中的应用 (Past Application)

### 案例 1: 某企业导入心智教育后的落地反馈（c05）

- **问题**: 企业内部八卦多、玻璃心态普遍、沟通成本高；管理上"和稀泥"，责任说不清；此前自认为的"人性化管理"实际是无规则、无边界感。
- **方法论的使用**: 按 HR 四模块（f13）逐项动手——培训以心智教育为核心而非技能补课；管理动作改为"人与事分离 + 岗位第一责任人制"；把员工从被管理者位置往自我成长者位置移（自下而上，ce22 的正向做法）。
- **结论**: 内耗的根源不是员工素质，而是规则与边界缺位被误当成"人性化"；组织心智需要先立规则、再谈成长。
- **结果**: 同事之间开始真诚交流、八卦减少；管理从和稀泥转为责任明确；员工主动思考降本（水电、采购、餐厅优化）；新人小朱半月业绩超老员工、杨经理开始对接大项目并带团队。沟通与运营成本下降，团队方向感提升。
- **⚠️ 本 skill 对本案例的处理**: 这条反馈里还有一项——"对价值观不同频的员工，主动补偿请退"。**本 skill 明确不采纳该动作**（ce03/ce45）：它是全书最可操作也最危险的一条建议，理由不可核验、不可申辩，最先被判"不同频"的往往是提异议、质疑加班、追问薪酬的人。要处理不胜任，用行为事实与岗位胜任力，不用"频率"。

### 案例 2（反例）: 价值观墙 vs. 冲量交付（ce18 + ce19 的复合失效）

- **问题**: 公司价值观墙写着"客户第一"，销售为冲量承诺明知做不到的交付。
- **方法论的使用**: 用五要素定位卡点——问题不在"员工素质"，而是卡在第 2 级"造价值"与第 3 级"做平衡"：公司只考业绩不考价值观（ce19），于是"客户第一"从来没有进入过任何一次真实取舍。价值观由老板发布或策划公司代写，员工背得出却举不出一件相关决策，这就是 ce18 的"装修"。
- **结论**: 价值观不落地的判据不是"宣导不够"，而是"与价值观冲突的行为长期无后果"。
- **结果（推导）**: 修法是把绩效改为平衡考核（业绩 + 取得方式）、晋升不绩优则仕（ce20）、招聘看同频度但须有成文标准以防 ce45——而不是再做一轮价值观宣讲会。

### 案例 3（反例）: 只送老板上课的变革（ce22 / ce21）

- **问题**: 企业采购心智培训，名单只有老板与高管，回来后以文件和晨会口号下发新理念。
- **方法论的使用**（作者用作反证）: 自上而下没有员工基础，理念变成新一轮服从要求，恰与"从被管理者到自我成长者"的目标相反。
- **结论**: 老板越热情，员工越沉默；员工能用新词汇复述，行为却零变化。
- **结果**: "心智教育"沦为老板的个人爱好。**若反向只对员工排课，则滑向 ce02——用"自敛/自管理"替代加薪、编制与流程修复。两侧同时排课、且员工侧配套可见权益改善，是唯一站得住的路径。**

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 老板/HR 说"我们价值观都写好挂上墙了，但员工好像根本不当回事"，想知道问题出在哪。
2. 价值观与业务动作互相打脸：墙上"客户第一"，实际为冲量承诺做不到的交付；墙上"诚信"，实际数据注水。
3. 绩效方案改不动：现在是大锅饭（优秀的人喊不公），或刚上末位淘汰（团队开始藏信息、互相碾压），问"到底该怎么考"。
4. 把业务尖子提成管理者，结果既丢了好销售又带崩一个团队，问晋升机制怎么设计。
5. 涨薪、股权、提成给到位了，一遇融资失败/增长停滞团队就散，问"怎么才能不是靠钱粘在一起"。
6. 企业主想做一次自我诊断："我公司到底卡在哪一步、下一个 90 天该做什么"。
7. 打算导入心智培训/企业心智教育，问"先培训谁、怎么排课、怎么验收"。
8. 招聘要不要把"价值观同频度"写进标准，以及怎么写才不越界。
9. 跨国/跨文化经营中信任成本高，想理解"资本安全阀"这一层。

### 与相邻 skill 的区分

- 与 `org-mind-diagnosis`（composes-with）的区别 —— **这是本 skill 最重要的一条分流**。`org-mind-diagnosis` 是 **C5 组织诊断总纲**：回答"这家公司的组织心智整体健康度如何、内耗从哪来、护城河在哪、要不要改造制度"，输入是组织症状，输出是全局体检报告。本 skill 是 **C6 价值观商业的落地与 HR 机制**：回答"一宗旨五要素卡在第几级、招聘/绩效/培训/员工管理这四个模块具体怎么改、90 天做什么"，输入是价值观与人事机制，输出是可执行清单。**典型顺序是先总纲后落地**：用 org-mind-diagnosis 判断"病在组织心智"，再用本 skill 落到五要素阶梯与 HR 四模块。反向地，若用户带着"绩效怎么考""要不要写进招聘标准"这类**机制级具体问题**进来，直接用本 skill，不必先走总纲。**不要双触发**：症状弥散（"公司氛围不对、内耗严重、说不清哪儿错了"）→ org-mind-diagnosis；抓手明确（价值观/招聘/绩效/晋升/培训/五要素）→ 本 skill。
- 与 `boss-mind-fourviews`（composes-with）的区别: 那是**老板个人的心智四观体检**（时代观/利益观/人才观/自我观），主体是"老板这个人"；本 skill 主体是"公司这套机制"。交界点是 ce44——当"顺平衡"被老板当成拒加薪拒扩编的话术时，问题已经不在机制设计而在老板的利益观，此时转 boss-mind-fourviews。判据：用户在问"我该怎么设计"→ 本 skill；用户（或其下属）在问"老板拿这套话术压我"→ boss-mind-fourviews（或 workplace-pua-guard）。
- 与 `startup-wealth-safety`（composes-with）的区别: 那是 C7 财富安全（死亡曲线/三陷阱/无安全慎发展），处理的是**扩张与风险的量级判断**；本 skill 处理价值观与人事机制。"逆发展"是二者的公共入口——但要不要刹车这个问题，涉及现金流、赛道结构、对手抢先后果时归 startup-wealth-safety；涉及价值观与组织落地时归本 skill。
- 与 `corp-mind-coach`（composes-with）的区别: 那是**心智教练这一职业角色的交付方式与认证**（g11）；本 skill 是甲方视角的落地内容。企业要"买什么、验什么"用本 skill，教练要"怎么交付"用 corp-mind-coach。
- 与 `workplace-relation-rebuild`（composes-with）的区别: ce19 的末位淘汰把同侪推向对立，这条后果的**个体侧修复**属 workplace-relation-rebuild（同事关系重构）；**机制侧修改**属本 skill。一个员工问"同事都防着我怎么办"→ 前者；HR 问"考核制度是不是把人逼成这样"→ 本 skill。
- 与 `workplace-pua-guard`（contrasts-with）的区别: **镜像关系**。本 skill 给管理侧工具，workplace-pua-guard 防的正是这些工具被滥用（用"你不同频""要顺平衡""先做好自敛"打压个人）。当提问者是被管理的一方时，一律优先 workplace-pua-guard。
- 与 `bata-business-boundary`（contrasts-with）的区别: 那处理心智学商业化本身的红线（培训/服务的夸大与资质问题）；本 skill 只在"采购与验收心智培训"这一点上与它相接——若用户在问"三天培训能不能上岗、能不能开店"，那是 bata-business-boundary。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行:

1. **红线预筛（必须最先做，不可跳过）**
   - 完成标准: 明确确认用户的真实意图**不是**下列三类——①想用"价值观不同频"为已定的裁员/劝退找理由（ce03）；②想用"情感频率/能量共振/同频"做招聘筛选或团队清洗（ce45）；③想用"逆发展·顺平衡"包装拒加薪、拒扩编、拒投入（ce44）。
   - 判停条件: 命中任意一项 → **不提供该用法**，直接说明风险（不可核验、不可申辩、可能构成就业歧视），并给替代路径：用行为事实 + 岗位胜任力 + 成文标准处理人事，用财务与赛道数据处理投入决策；涉及解雇合法性时明确告知需咨询劳动法专业人士。本 skill 不出具"同频度评分表"这类工具。
   - 完成标准（补充）: 声明口径——心智学不是医疗，不作任何心理或医学诊断；本 skill 输出是管理建议，不构成法律意见。

2. **确认提问者的位置**
   - 完成标准: 明确用户是**决策方**（老板/HR/顾问，有机制改动权）还是**被管理方**（员工）。
   - 判停条件: 若是被管理方且诉求为"应对上级用这套话术压我" → 转 `workplace-pua-guard`，本 skill 不作为管理话术的供给方。

3. **四特征验尺（先判真伪，再谈落地）**
   - 完成标准: 逐条核对 f10/p51 四特征并给出"有/无/存疑"——①市场原则是多方平衡还是单方利益最大化；②经营诉求是量场存续还是短期规模；③**是否有以安全感为基础的达成感（全员敢试错、敢报坏消息，这一条最难伪造，重点问最近一次有人报坏消息的后果）**；④跨国场景下价值观是否起到资本安全阀作用（无跨国业务则标注不适用）。
   - 完成标准（补充）: 同步跑 ce18 三条预警——员工能否背出、**能否举出一件与价值观相关的真实决策**、与价值观冲突的行为是否长期无后果。三条中命中两条即判定为"褒义词上墙/空装修"，并明确告知：**修法不是再宣导一轮**。

4. **五要素卡点阶梯诊断（自下而上找第一个断裂点）**
   - 完成标准: 按 1→5 顺序逐级核验并**停在第一个断裂点**：①办公司→办量场（是否只算利润不算量场）；②造产品→造价值（是否在卖东西而非造价值）；③做经营→做平衡（是否只有单方利益最大化）；④劳资双方→量场共识（是否仍是纯雇佣对价）；⑤企业文化→价值观同频（是否只有文化活动没有取舍标准）。产出一句话结论："你卡在第 N 级——<具体行为证据>"。
   - 完成标准（补充）: 每一级判定必须挂一条**可观察行为事实**，不接受形容词式判断（"我们平衡做得还行"不算证据）。
   - 判停条件: 若卡点在第 1–2 级（连量场/价值定义都未成立），**不要直接跳到 HR 四模块**——先做经营观与产出观的对齐，否则四模块会变成新一轮 KPI；若用户症状弥散、说不清具体机制 → 转 `org-mind-diagnosis` 做总纲诊断后再回本 skill。

5. **一宗旨对照 + 刹车条件评估（ce17 强制步骤）**
   - 完成标准: 对"逆发展"给出**量化前置判据**，而不是德性判断——所在赛道是否具强网络效应/赢家通吃/技术窗口极短（平台、标准竞争、前沿硬科技）；对手抢先完成锁定的后果是什么；现金流与安全垫状况（此项转 `startup-wealth-safety`）。对"顺平衡"逐条落到利益相关者/内外/长短期三组平衡，各写一条本季度可验证的动作。
   - 判停条件: 若用户拿"逆发展"解释一切不敢做的决定、且从未评估对手抢先后果 → 明确指出这是 ce17 的失效模式，本 skill 不为该决定提供价值观背书。

6. **HR 四模块整改清单（逐模块给动作 + 挂红线）**
   - 完成标准: 输出四张清单，每张 2–3 条本月可动手的动作。
     - **招聘**：胜任力标准成文化 + 价值观相关的**行为面试题**（问过去做过什么，不问理念是否认同）；**禁止**"频率/能量/共振"类表述与不公开、不可量化的主观打分（ce45）；不同频不得作为拒录唯一理由。
     - **绩效**：平衡考核 = 业绩 + 取得方式（是否符合价值观）；**同时避开两个极端**——分布高度集中的大锅饭、一刀切末位淘汰（ce19）；管理者必须能说出具体行为事实而非只给分数。
     - **培训 / 晋升**：培训以认知与心智为核心；**建立专业通道，晋升不以绩优则仕**（ce20）；晋升评估纳入协作、授权、冲突处理等维度；检查"是不是只有升管理一条奖励路径"。
     - **员工心智管理**：自下而上、先基层后老板；**两侧同时排课**（只做老板层=无基础空转 ce22；只做员工层=软性管控 ce02）；员工侧必须配套可见的权益改善或流程修复，验收指标写成"员工可自主行使的权利/被解决的流程问题"，**不得写成"降低离职率/降低管理成本"**。
   - 完成标准（补充）: 检查凝聚手段是否只有钱与期权（ce21 三条预警：谈留人只谈钱、关键成员对"公司在做什么"表述不一致、一次降薪即集体动摇）。

7. **90 天"量场维系者"行动方案（f14）**
   - 完成标准: 只针对第 4 步定位的**那一级卡点**，产出 30/60/90 天三段方案，每段含：1 个可观察的行为指标（不是满意度自评）、1 个负责人、1 条"做不到就回退"的判停条件。整个方案里至少有一条是**约束管理侧/老板侧**的动作，若通篇只在要求员工改变，方案不合格，退回第 6 步重做。
   - 完成标准（补充）: 90 天末的复检口径写清楚：ce18 三条预警是否下降、是否出现新的红线滑坡（有没有人开始用"不同频"说话）。

8. **收尾复述**
   - 完成标准: 用户能说出三句话——"我卡在第 N 级，证据是 X"、"这个月我先改 HR 的哪一个模块、第一步做什么"、"这三条我不会做（不同频请退 / 频率筛人 / 用顺平衡砍员工侧成本）"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户想要的是一套漂亮价值观文案上墙**：这正是本书判定的失效模式（ce18），照做等于交付一份"装修"。
- **用户已决定裁员/劝退，只是来找一个说得出口的理由**：本 skill 不提供"价值观不同频"这类理由（ce03/ce45）。
- **解雇合法性、补偿标准、劳动合同争议**：需劳动法专业人士，本 skill 输出不构成法律意见。
- **提问者是被管理的一方**（被上级用"不同频/自敛/顺平衡"施压）→ `workplace-pua-guard`；本 skill 不为管理侧提供施压话术。
- **组织症状弥散、说不清卡在哪个机制** → 先 `org-mind-diagnosis`（C5 总纲）。
- **核心问题是老板个人的利益观/人才观** → `boss-mind-fourviews`。
- **核心问题是现金流、扩张时机、财富与安全的量级判断** → `startup-wealth-safety`。
- **任何心理健康与医学场景**：员工出现抑郁、自伤风险、精神症状时，立刻走 EAP/医疗转介，**不得把它处理为"心智不成熟"或"价值观不同频"**。心智学不是医疗，不作诊断，不替代任何医学评估。

### 作者在书中警告的失败模式

- **ce17 「逆发展·顺平衡」被当作普适律（本 skill 最大的适用范围风险）**：在强网络效应、赢家通吃、技术窗口极短的赛道（平台、标准竞争、前沿硬科技）里执行"主动刹车"，把生死攸关的速度与规模当成"贪妄"压制，等对手完成网络锁定后再无入场机会——"逆发展"从战略定力退化为对增长的道德化恐惧。**根因是作者未给出适用条件**（行业竞争形态、规模经济强度、窗口期长短），读者无法判断何时刹车是定力、何时是错失。预警：拿"逆发展"解释所有不敢做的决定；从未评估对手抢先的后果；把增长当价值观问题而非结构问题；决策语言全是德性词、没有一条量化条件。**处置：任何"刹车"结论必须附带对手抢先后果评估与现金流判断（第 5 步强制）。**
- **ce18 价值观 = 褒义词堆砌上墙**：由老板发布、管理层合议或策划公司代写，落地形态只有墙面与手册；员工"嘴上认可心里不信、表面服从行动抵触"，危机时毫无约束力，还额外制造愤世嫉俗（说一套做一套的公开证据）。机制在于生成过程排除了实际执行者，价值观从未与任何人的真实取舍发生关系。预警：员工背不出，**或背得出但举不出一件相关决策**；来自外部策划案、无全员参与痕迹；与价值观冲突的行为长期无后果。
- **ce19 绩效两极端（大锅饭 / 末位淘汰）双双失效**：一端"一碗水端平"→ 大锅饭 → 优秀者感到不公 → 劣币驱逐良币；另一端末位淘汰一刀切 → 恐惧焦虑常态化 → 同侪互相碾压、藏信息、把同事变对手。**真实动机分别是管理者对人际冲突的恐惧、以及把评价责任外包给排名规则**——两者都在回避"面对面给出有依据的差异化评价"这件难事。预警：考核分布高度集中；管理者只能给分数说不出行为事实；团队开始提防同事；高绩效者离职理由是"不公"。
- **ce20 「绩优则仕」式晋升**：把业务尖子直接推上管理岗，同时损失一个优秀执行者和一个被不胜任管理者带坏的团队；晋升成了唯一激励货币，想加薪只能去管人。预警：唯一奖励路径是升管理；新任管理者仍包揽核心业务活儿；晋升考核完全没有认知/心智维度。
- **ce21 纯利益纽带养出"逐利团伙"，以利诱之、利尽人散**：以涨薪股权提成为唯一凝聚手段，上行期看起来凝聚力很高，一旦利益预期下调（融资失败、增长停滞、期权归零），组织数周内解体并带走客户与资料。机制是单一激励只筛选出对该激励最敏感的人，且这种纽带"可被出价更高者接管"——凝聚力与对手报价成反比。
- **ce22 自上而下先打动企业家的变革失败**：只把老板高管送去上课，再由上至下颁布新理念；基层没有共同语言与切身收益，新词汇被当成又一轮运动，老板越热情员工越沉默。**必须与 ce02 成对使用**：只做员工层 = 用"自敛/自管理"替代加薪、编制与流程修复的软性管控；只做老板层 = 无基础空转。**唯一站得住的做法是两侧同时排课 + 员工侧配套可见权益改善。**
- **ce44 「逆发展·顺平衡」被用作拒资、拒扩编、拒加薪的正当化话术**：老板把战略定力偷换成成本借口，用"不能摧毁根基/要守护量场"拒绝合理的加薪、编制、设备与培训投入，员工看到的是薪资停滞工具老化、听到的是"我们在做平衡"。根因是框架缺硬指标（何为量场存续、阈值多少均无解），"平衡"于是成为不可证伪的否决权、掌握在付费方手里。预警：顺平衡只用来砍员工侧成本、不约束老板侧冒险；老板个人扩张消费照旧；量场存续从不被量化；平衡叙事与同期利润/融资数据明显背离。
- **ce45 用"情感频率/同频"做招聘与团队清洗（歧视红线）**：把不可观测、不可证伪的"频率"当客观筛选标准，把主观好恶与年龄/性别/风格偏见包装成"能量频段不合"的科学结论——**用伪科学话术掩盖就业歧视，且当事人无法申诉（你无法证明自己"同频"）**。预警：录用/淘汰理由出现"频率、能量、共振"等非行为描述；标准不公开、不可量化、由面试官主观给；被筛掉的人呈现稳定的年龄/性别/风格特征；拒绝给出基于胜任力的具体反馈。
- **ce03 以"价值观不同频"为由请退员工（全书最可操作也最危险的一条）**：绩效与岗位胜任力这些可举证标准，被一个主观频率判断覆盖；**异见者、举报者、追问薪酬与加班的人最容易被判为"不同频"**。"主动补偿"只处理金钱，不处理判断权的滥用，不能当作程序正当性的替代品。**本 skill 明确不采纳这一动作**，即使它出现在书中的正面案例 c05 里。

### 作者的盲点 / 时代局限

- **关键概念全部缺少度量**："同频""量场存续""平衡"没有任何操作化定义与阈值，却被直接写进用人与预算决策。无度量标准一旦进入人事权，必然回填为"老板是否喜欢你"。这不是执行偏差，是框架自身的结构性缺陷——因此本 skill 的每个抓手都必须配一条行为事实要求。
- **结构问题个体化**：组织心智被定义为"个体心智的汇聚"，于是制度失序（排班混乱、需求朝令夕改、审批黑洞）在模型里没有位置，改造人比改造制度便宜，ROI 叙事天然指向前者（ce02）。使用时须主动把制度侧问题拉回议题。
- **单方视角偏斜**：全书站位以经营方为主，"逆全球化""价值观筛选世界"等宏观断言属格言式研判，无实证与数据支撑；四特征、五要素均无量表与效度检验，属教学框架而非诊断工具。
- **劳动关系不对称被弱化**："从劳资双方到量场共识"在理念上很美，但雇佣关系中权力与信息本就不对称，"共识"若没有制度化的员工发声与救济渠道，很容易变成一方定义、另一方接受。
- **法律与合规视角缺位**：招聘同频度、请退不同频等建议未考虑就业歧视与劳动法风险，跨司法辖区差异更未涉及。
- **非医疗声明**：心智学不是医疗、不作诊断；员工心理健康议题须走 EAP 与专业医疗渠道，不得以"心智不成熟"替代评估。

### 容易混淆的邻近方法论

- **价值观 ≠ 企业文化**（g12）：文化是活动、口号、氛围；价值观是**冲突时刻的取舍标准**。判据只有一条：能不能举出一件因它而放弃利益的真实决策。
- **平衡考核 ≠ 强制分布 / 360 评估**：ce19 反对的是"用规则替代面对面的差异化评价"；强制分布恰恰是这种替代的典型形态。
- **价值观同频 ≠ culture fit 面试**：欧美 culture fit 已被大量批评为同质化与偏见通道；本书的"同频"因为没有度量，风险更高一级（ce45）。可用的替代物是**基于行为的结构化面试 + 成文胜任力标准**。
- **逆发展 ≠ 收缩 / 保守经营**：它在本书里是"有所为有所不为"的战略定力，但缺少适用条件；把它等同于少花钱，就直接落进 ce44。
- **自下而上 ≠ 只培训员工**：ce22 与 ce02 是一对张力，正确形态是双侧同时推进，且员工侧要有可见收益。
- 与"做一次价值观共创工作坊"这类通用做法的区别: 本 skill 给的是**有顺序的卡点阶梯 + 四个可改的 HR 机制 + 三条硬红线**，重点不在共创过程，而在"哪一级断了、哪个机制改完能看见行为变化"。

## 相关 skills

**composes-with（经常配合使用）**

- `org-mind-diagnosis`（C5 组织心智诊断总纲）：**分工最清晰也最需要防抢调用的一对**。它做全局体检（组织心智健康度、内耗来源、护城河），本 skill 做价值观落地与 HR 机制整改。标准链路：症状弥散 → org-mind-diagnosis 定位"病在组织心智" → 本 skill 落到五要素阶梯与四模块 → 90 天方案。反向：本 skill 在第 4 步若发现卡点在第 1–2 级、经营观本身未立，交回 org-mind-diagnosis。两者共享 ce02/ce18 两条反例。
- `boss-mind-fourviews`（老板心智四观）：交界点是 ce44。机制设计不动、老板利益观不改时，任何 HR 整改都会被"顺平衡"话术抵消，此时先做老板侧四观体检再回本 skill。
- `startup-wealth-safety`（C7 财富安全：死亡曲线/三陷阱/无安全慎发展）：本 skill 第 5 步的"刹车条件评估"直接调用它——现金流、安全垫、扩张时机的量级判断在那边，价值观与组织落地在这边。ce17 的解药一半在它手里。
- `corp-mind-coach`（企业心智教练与 IAMS 认证，g11）：甲方"买什么、验什么"用本 skill 的第 6/7 步；乙方"怎么交付"用它。企业采购心智培训时两者串联。
- `workplace-relation-rebuild`（同事关系重构）：ce19 末位淘汰造成的同侪对立，机制侧修改在本 skill，个体侧修复在它那边。

**contrasts-with（互为镜像 / 用于制约）**

- `workplace-pua-guard`（职场 PUA 识别与防护）：本 skill 输出的管理工具（同频、自敛、顺平衡）正是它要防的滥用话术。**位置判据优先于内容判据**——提问者是被管理方时一律优先它，本 skill 不作为管理话术供给方。
- `bata-business-boundary`（心智学商业化边界）：仅在"采购与验收心智培训"这一点相接；涉及"三天培训上岗、开店、夸大宣传"一律归它。
