# 创业财富安全：死亡曲线 / 三陷阱 / 无安全慎发展

## R — 原文 (Reading)

> "财富与安全感并非简单的正比关系，它们关系更像一条抛物线。当财富规模达到某个'转折点'时，情况会急转直下：管理复杂、成本沉重、竞争加剧、舆论与社会责任风险上升、个人精力健康透支，微小波动可能引发海啸，击穿轴线双双归零。"
>
> — 意师, 第六章 第三节（三）1 发展悖论：财富与安全的死亡曲线

> "警惕三个陷阱：陷阱一，把偶发当常态（偶然胜利误读为必然）；陷阱二，把侥幸当能力（时势造英雄错当自己本事）；陷阱三，把放任当宽容（管理失序误认团队能力）。"
>
> — 意师, 第六章 第三节（三）2 避免死亡曲线，警惕三个陷阱

> "对于这三个陷阱，请把握六个字：'无安全，慎发展'。在你没有构建起坚实的企业价值观、稳定现金流和清晰的风险应对机制之前，任何冒进发展，都是在为未来挖坑。"
>
> — 意师, 第六章 第三节（三）

## I — 方法论骨架 (Interpretation)

这是一张"创业者财富—安全"的刹车图，把"钱越多越安全"的线性直觉换成一条抛物线，再标出三处把人推过转折点的心智盲区。

**死亡曲线（g07，财富死亡曲线）**：财富与安全感是倒 U 形，不是正比。上升期财富确实提升安全感；但跨过某个看不见的"转折点"后，规模带来的变量（管理、成本、竞争、舆论、健康）增速超过驾驭能力增速，安全感反向下行，一次黑天鹅就能把两者一起击穿。它的价值是**反直觉警示**，不是数学预言。

**三心智盲区（f12，三陷阱）**：书把"为什么会踩过转折点"具体命名成三种可识别的认知失误——①偶发当常态（一次风口/大单＝可无限复制的规律）；②侥幸当能力（上行周期的红利＝自己的本事）；③放任当宽容（管理失序＝团队自治）。三者共同的机制是用过去的成功经验替未来做全额担保。

**无安全慎发展（g08，六字箴言）**：把"发展节奏"绑回安全基线——价值观、现金流、风险机制三样没稳之前，规模本身就是风险放大器。它是死亡曲线的行动结论、三陷阱的刹车阀。

⚠️ **关键边界（ce13）**：这条曲线无数据、无阈值、转折点不可事前测定。它只能当**风险清单**用，不能当**预测模型**——你无法用"死亡曲线"算出自己的公司哪天会崩。

## A1 — 书中的应用 (Past Application)

### 案例 1: 28 岁创业者的迷茫焦虑与婚姻困境（c02，书作者用作三陷阱反例）

- **问题**: 男/28/创业者，夫妻分居三年、女儿曾抑郁辍学，妻子求离；公司经营不善已退出经营，再创业与求职皆受阻，情绪低落、对女儿学业焦虑。
- **方法论的使用**: 书把这位创业者的经历作为"偶发当常态／侥幸当能力"的反例素材——早前的成功被读成可复制能力，未稳即扩张与再创业，安全基线缺失。
- **结论**: 创业者的崩溃不在"不够努力"，而在把偶发胜利当规律、把阶段性红利当本事，越过转折点后变量反噬。
- **结果**: 经 BMC 心智疏导后能面对自我、久违地开心一整天；作为"三陷阱"教学反例，提醒读者先稳安全再谈发展。

### 案例 2: 陷阱一·把偶发当常态（ce14，小样本 n=1 全押）

- **问题**: 抓住一次风口、赢下一个大单，便认定这是可无限复制的常态，据此全押产能、人员、库存与负债。
- **方法论的使用**: 小样本（n=1）+ 结果为正，是强化学习最猛的组合；归因偏差把外部时点/政策/渠道红利读成内部能力，全押又切断了纠错空间。
- **结论**: 用峰值收入做长期固定成本承诺（租约、编制、产线）＝红线；说不清这次成功里"运气占几成"时，不得按常态扩张。
- **结果**: 风口退去，成本结构已按峰值搭建，瞬间崩塌。

### 案例 3: 陷阱二·把侥幸当能力（ce15，上行周期红利错当本事）

- **问题**: 行业上升期成功相对容易，创业者把"时势造英雄"的侥幸错当成自己无所不能的本事。
- **方法论的使用**: 上行周期会掩盖认知滞后（"老板认知滞后，也能被时代红利托起"），红利期不提供负反馈，能力错觉无法被纠正。
- **结论**: 越成功越听不进异见、进入陌生领域仍高度自信，是对市场警觉丧失的信号。
- **结果**: 周期反转时一次性结账——之前被托起的认知滞后全部暴露。

### 案例 4: 陷阱三·把放任当宽容（ce16，管理失序误认团队能力）

- **问题**: 对团队问题视而不见、对不合理成本听之任之、对战略摇摆不决，并用"宽容/人性化"自我合法化。
- **方法论的使用**: 与"宽容≠不追究"同源——回避冲突的短期收益即时可得，秩序崩塌的成本延迟且分散；管理者用褒义词给回避行为贴道德标签。
- **结论**: 这不是宽松，是失序；认真做事的人先失去安全感，信任与秩序被侵蚀。
- **结果**: 同类问题反复出现无人被追责，优秀员工陆续离开，问题员工留存。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 拿到一笔大单/一轮融资后，想立刻全押产能、扩团队、加杠杆，并相信"再做几单就安全了"。
2. 把一次成功（风口、大客户、政策红利）当规律，开始对外输出"我的方法论"，或进入完全不熟悉的领域仍高度自信。
3. 公司管理混乱、成本失控、战略摇摆，却用"我们人性化/团队自己能转"解释，不愿立规则追责。
4. 在"扩还是不扩"之间纠结，且倾向于用"不扩张就会死"来证明扩张必要，却说不出不扩张的具体后果。
5. 想用"死亡曲线"预测自己公司何时会崩、何时到转折点——这是本 skill 必须拒绝的预测用途（见 B）。

### 语言信号 (用户的话里出现这些就应激活)

- "再做大一点就安全了 / 做大做强才抗风险 / bigger is safer"
- "上次就是这么成的，这次也一样 / 偶发当常态 / one-off as norm"
- "这个风口赶上了，说明我行 / 侥幸当能力 / luck as skill"
- "团队自己能转，我放手是信任 / 放任当宽容 / laissez-faire as tolerance"
- "无安全慎发展 / no-safety-no-growth / 先稳再扩"
- "用峰值收入租下长租约、扩了编制 / 峰值收入做长期承诺 / peak-revenue commitment"

### 与相邻 skill 的区分

- 与 `boss-mind-fourviews`（composes-with）的区别：boss-mind-fourviews 诊断老板"四观"（利益/员工/风险/价值观）这一**量场源头变量**；本 skill 聚焦**财富—安全感抛物线 + 三陷阱刹车**，是源头心智在"发展与安全"上的具体表现。配合：先用四观看源头，再用本 skill 看量变曲线，二者同一创业者、可串联。
- 与 `org-mind-diagnosis`（composes-with）的区别：org-mind-diagnosis 评估"成人型心智占比＝组织护城河"；本 skill 的陷阱三（放任当宽容）正是组织失序的成因之一，可联动——当自查命中陷阱三，转 org-mind-diagnosis 看组织健康度。
- 与 `value-business-hr`（contrasts-with）的区别：二者同源（"逆发展·顺平衡"一宗旨），但 value-business-hr 落 HR/经营四模块与卡点阶梯诊断；本 skill 只取"刹车"的**创业财富安全**维度，不展开价值观企业落地。
- 与 `workplace-pua-guard` 的区别：完全不同——那识别上级精神控制，与创业财富安全无关，勿混淆触发。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行：

1. **死亡曲线自检（识别转折点附近信号）**
   - 完成标准: 让用户逐条核对——现金流与价值观尚未成型即扩张、个人健康/家庭时间被计为可透支项、安全感自评随规模上升反而下降、"不扩张就会死"却说不出具体后果。命中 ≥2 条 → 提示已接近或越过转折点区域（⚠️ 仅作风险清单，非预测）。
   - 判停条件: 若用户要求"算出公司哪天崩/转折点具体数值" → 跳到步骤 4 的边界声明，明确拒绝预测。

2. **三陷阱自查（命名具体心智盲区）**
   - 完成标准: 让用户把近期一个扩张/决策对标三盲区——① 偶发当常态（样本量 n=? 运气占几成？）；② 侥幸当能力（成功里多少是周期红利？身边是否只剩附和者？）；③ 放任当宽容（同类问题是否反复无人追责？"算了下不为例"是否常用？）。每项给出"是/否/部分"与一句证据。

3. **无安全慎发展决策闸门（三问）**
   - 完成标准: 对拟议的冒进动作，三问须全过才放行——**价值观稳了吗？稳定现金流覆盖长期固定成本了吗？清晰风险机制（含最坏情形）建了吗？** 任一不过 → 输出"刹车：先补安全基线，再谈这一步"，并给出本周可做的第一项补强动作。

4. **输出决策 + 标注曲线性质**
   - 完成标准: 给出"扩/缓/停"结论与理由，并明确附一句："死亡曲线无数据无阈值，只用于提示风险、不能预测你公司何时崩（ce13）。" 不替用户做财务/法律最终决定，重大动作建议同步专业机构。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 已出现财务崩盘、债务违约、法律诉讼、创始人精神健康危机等需专业机构介入时：本 skill 只做心智盲区自检，不替代财务/法务/医疗处置。
- 纯融资结构、财税、法务技术咨询：转对应专业服务。
- 用户要的是员工心智成长或组织诊断：转 `boss-mind-fourviews` / `org-mind-diagnosis`。
- 用户描述的是上级精神控制或招聘歧视：转 `workplace-pua-guard`。
- 用户要求用死亡曲线"预测公司何时崩/转折点数值"：必须拒绝，只提供风险清单（见 ce13）。

### 作者在书中警告的失败模式（CRITICAL）

- **ce13 死亡曲线不是预测模型**：该曲线无数据、无阈值，转折点不可事前测定。只可当风险清单用，不可当预测模型。任何"算出你公司 X 月崩"的回答都越界，须退回"提示风险变量"的用途。
- **ce14 小样本 n=1 不得全押**：一次风口/大单成功不得全押产能、人员、库存与负债；用峰值收入做长期固定成本承诺（长租约、编制、产线）＝红线。说不清"运气占几成"时不得按常态扩张。
- **ce15 上行周期红利不得错当个人本事**：行业上升期的成功不提供负反馈，能力错觉无法被纠正；周期反转会一次性结账。把周期性成功写成个人方法论对外输出、进入陌生领域仍高度自信，是危险信号。
- **ce16 管理失序 ≠ 宽容**：把对问题视而不见、成本听之任之、战略摇摆不决包装成"宽容/人性化"，是对组织安全感的最大漠视，会在内部侵蚀信任与秩序。

### 作者的盲点 / 时代局限

- **曲线缺实证基础（ce13 同源）**：死亡曲线属格言式忠告，无统计阈值；使用时应如实告知用户其"风险清单"属性，不得放大为量化模型。
- **"老板心智决定天花板"不可证伪（ce11 邻近）**：本 skill 聚焦财富—安全，但不把创业成败单因归于"心智"——行业周期、政策、资本、团队、运气同样关键；对失败者不作归因暴力。
- **"逆发展"的适用条件未给出（ce17 邻近）**：强网络效应/技术窗口极短的赛道里过度刹车可能错失，本 skill 的"慎发展"须结合行业结构判断，不机械套用。
- **心智学非医疗**：本书把身心困扰归因于心智成长，但本 skill 涉及的健康透支、焦虑、关系破裂等，出现精神健康危机须转介专业机构；心智学不作诊断、不替代任何医学评估与治疗。

### 容易混淆的邻近方法论

- **风险清单 ≠ 预测模型**：死亡曲线提示"越过转折点更危险"，不承诺"何时、以何方式崩"。
- **宽容 ≠ 不追究（ce39/ce16）**：真宽容有宽恕四前提（承认事实/担责/反噬/审核）；无前提的"算了"是纵容，即陷阱三。
- **刹车 ≠ 不发展（ce17）**："无安全慎发展"是主动刹车而非拒绝增长，须评估对手抢先后果。
