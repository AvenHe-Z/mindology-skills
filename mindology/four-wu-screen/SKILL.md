# "四无"现象筛查与五维成长方案

## R — 原文 (Reading)

> "学习无动力、社交无能力、生活无兴趣、生命价值无感——这四种表现正从个别案例演变为群体特征。它不是某一种具体的心理疾病，而是整体心智成长滞后的综合表征。"
>
> — 意师, 第六章·中国青少年心智研究报告 / AI时代附录

---

## I — 方法论骨架 (Interpretation)

"四无"是本书对中国青少年普遍性心智滞后状态的聚合诊断标签，把分散的困境（厌学、孤僻、无聊、空心）统一收拢到四个维度：学习无动力、社交无能力、生活无兴趣、生命价值无感。它**不是单一心理疾病**，而是一面"整体心智成长滞后"的镜子。

配套的"五维成长方案"给出对应发力点：①情绪觉察与自我调节 ②同伴关系与边界意识 ③亲子互动与情感表达 ④独立思考与信息甄别 ⑤自我约束与自律素养。用法是先"四无筛查"定位最弱的维度，再映射到五维工具逐维补强——思路是"评估—成长"而非"诊断—治疗"。C10 的权威数据（约3000万未成年人受情绪障碍困扰、抑郁风险14.8%、6–12岁日均电子设备3.2h而亲子深度对话仅15min）作为四无扩散的结构性佐证并入本技能作论据附录。

---

## A1 — 书中的应用 (Past Application)

### 案例 1：中国青少年心智研究报告数据——佐证"四无"已从个别变群体（c13）
- **问题**：如何论证青少年"懒/宅/没劲/没意义"不是个别熊孩子，而是群体性结构危机。
- **方法论的使用**：以权威数据（柳叶刀/心理健康蓝皮书/未成年网民报告）作四无扩散佐证——约3000万17岁以下未成年人受情绪障碍困扰，抑郁风险14.8%，日均电子设备3.2h、与父母深度对话仅15min，留守/缺关怀者抑郁风险+40%，住校网民依赖34.3% vs 双亲同住18.0%。
- **结论**：四无正从个别案例演变为群体特征，印证"整体心智成长滞后"而非单点病症。
- **结果**：本书据此主张以"成长导向"替代"治疗导向"，作为本技能的数据支点（数据有时效，引用须标注来源，不替代医学/政策结论）。

### 案例 2：儿子"整天打游戏、不交朋友、说活着没意思"的筛查定位（verified C8·V2）
- **问题**：家长问"儿子打游戏、不交友、说活着没意思，是抑郁吗？"
- **方法论的使用**：先用四无筛查"学习无动力/社交无能力/生活无兴趣/生命价值无感"四维度，确认其在多个维度同时偏低；再用五维成长方案对应"情绪觉察/同伴边界/亲子互动/独立思考/自我约束"逐维给工具，并联动 youth-issue-decode 判断是否需医学排雷（空心病≠抑郁，但须排除自伤/幻觉等红线）。
- **结论**：问题更像整体心智成长滞后在动力—能力—兴趣—价值感四维的系统性表征，而非可单点贴"抑郁"标签。
- **结果**：定位到发力点后转向成长路径；同时因存在"活着没意思"表述，触发排雷流程，确认无高风险信号才纳入成长方案而非擅自处置。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 家长/老师说"孩子啥都不想干、懒、宅、没劲、没意义"，想弄清是哪一维出了问题。
2. 青少年自述"活着没意思/没动力/交不到朋友"，想自我定位而非直接贴病理标签。
3. 想用权威数据理解青少年心智危机的结构性成因，做科普或家校沟通。
4. 已用五层/情感频率测过，想进一步落到"四无×五维"的具体发力点。
5. 担心孩子"空心病"但又怕被过度病理化，需要去病耻化的成长视角（联动 growth-orientation-ai）。

### 语言信号（用户的话里出现这些就应激活）

- "孩子懒/宅/没劲/对啥都没兴趣"
- "说活着没意思 / 不知道为了什么"
- "学习没动力、交不到朋友、天天刷手机"
- "这是不是抑郁 / 还是单纯不想努力"
- "现在小孩心理问题怎么这么多"

### 与相邻 skill 的区分

- 与 `youth-issue-decode`（composes-with，C3）的区别：本技能是**四无筛查 + 五维发力点地图**（整体心智滞后在四维度上的聚合表征）；C3 是**单议题心智学归因与处置**（手机PSU/厌学/叛逆/空心病/高考焦虑各一节 + 发育视角 + 转介红线）。配合方式：用本技能的"四无×五维"做整体定位后，若落到具体议题（如手机沉迷、厌学），转 C3 取归因卡与家长行动清单；C3 遇高风险信号则转 bmc-youth-boundary。
- 与 `growth-orientation-ai`（branch-skill，C11）的区别：本技能聚焦"四无"这一具体聚合概念与五维工具；C11 是总开关（去病耻化的成长导向范式 + AI时代五点回应）。本技能是 C11 范式在"四无"议题上的落地。
- 与 `youth-mind-level-test` / `youth-emotion-frequency-test`（branch-skill）的区别：那两个是层级/频率的测评镜；本技能是"四无"聚合筛查 + 五维成长方案，测评结果仅作成长参考、不作临床标签（见 B 段）。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **四无筛查：逐维打勾定位**
   - 完成标准：对照"学习无动力 / 社交无能力 / 生活无兴趣 / 生命价值无感"四维度，列出用户当前最弱的 1–2 维，并确认四无是"整体心智成长滞后"的表征而非单一疾病。
   - 判停条件：若用户出现自伤/自杀意念、他伤风险、幻觉妄想、明显神经认知损伤、严重成瘾等高风险信号 → 立即跳到步骤 4（转介），不在本技能内继续成长方案。

2. **五维映射：把弱维落到成长工具**
   - 完成标准：将最弱维度对应到五维成长方案——情绪弱→情绪省察期/自我回归期；同伴弱→互敬/边界/自敛；亲子弱→行为描述法/三转向；独立弱→拼板/置换/信息甄别；约束弱→后果自负/体验匮乏/自敛。给出 1–2 项可执行练习。

3. **数据旁证（可选）**
   - 完成标准：如需向外论述"四无扩散"的结构性，可引用 C10 并入数据（约3000万/14.8%/3.2h），并标注来源与时效，明确"数据非方法论、不替代医学结论"。

4. **排雷与收尾**
   - 完成标准：再次确认无高风险信号；向用户说明"四无筛查与五维方案是成长参考，不是诊断"，并指明何时该转专业医疗（见 B 段）。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **出现高风险信号时**：自伤/自杀意念、他伤风险、幻觉、妄想、明显神经认知损伤、严重成瘾、器质性病变、重性精神障碍——立即转介 bmc-youth-boundary 与专业医疗/精神科，四无筛查不得替代医学评估（ce01/ce17/ce18）。
- **需要用药或临床干预时**：本技能非医疗，不提供任何药物或临床处置建议。
- **把"四无"当终生命运标签**：四无是成长阶段表征，不是定终身的病理诊断；测试/筛查结果仅作成长参考（ce18）。

### 时效性数据使用规则（必读）
- 用户问"当前多少孩子受困 / 抑郁比例 / 屏幕时间 / 日均时长"等**具体数字**时，先核实最新权威来源（《柳叶刀—区域健康》《心理健康蓝皮书》等）并**标注年份**；本技能附带的 3000 万 / 14.8% / 3.2h / 15min 等为历史研判数据，引用须标注来源与时效，明确"数据非方法论、不替代医学/政策结论"。查不到更新来源时，说明数据版本与局限，不把旧数据称为当前现状。

### 作者在书中警告的失败模式

- **ce18 测评误用/标签化**：把五层、情感频率、四无筛查的结果当"诊断"给孩子贴"新星级/病态"标签，固化认知、延误医学介入；本技能明确筛查结果仅作成长参考。
- **ce17 去医学化漏诊**：ADHD、双相、发育性障碍被"四无/心智滞后"统一覆盖而漏诊；凡长期注意力/冲动/情绪极端波动，先排雷再谈成长（见 C9 红线）。

### 作者的盲点 / 时代局限

- 本报告数据引《柳叶刀》《心理健康蓝皮书》等主流医学数据论证危机，却同时批判心理学/精神医学范式，论证根基有裂缝；数据是时效性研判，引用须标注来源、不替代医学/政策结论。
- 本书把亲子冲突、手机沉迷、厌学大量归因于"心智不成熟"，弱化教育制度、同辈竞争、平台算法掠夺等结构因素（阶段0批判）。

### 容易混淆的邻近方法论

- "四无"≠ 单一心理疾病，也≠ 对一切痛苦去医学化；去病耻化成长视角**不否认重性障碍**（见 bmc-youth-boundary / growth-orientation-ai 红线）。
- **心智学不构成医疗诊断、不替代医学、高风险转介**：本技能是成长筛查与发力点地图，任何医学性质疑与高风险信号一律交专业医疗处置。
